# 本机技能体检（四件套命令速查）

> 本机 `~/.workbuddy/tools/` 下有四个技能库体检/维护脚本，统一用 WorkBuddy 托管 Python 3.13.12 运行。
> 适用于：技能整合/迁移/打包后验收、INDEX.md 索引重建、日常技能库巡检。

## 统一调用方式

```bash
PY="C:/Users/Matebook/.workbuddy/binaries/python/versions/3.13.12/python.exe"
TOOLS="C:/Users/Matebook/.workbuddy/tools"
SKILLS="C:/Users/Matebook/.workbuddy/skills"
```

## 四件体检命令

| # | 命令 | 作用 |
|---|---|---|
| 1 | `"$PY" "$TOOLS/skill-ref-audit.py"` | 引用审计：扫描各包 SKILL.md/references 里的引用，检出幽灵引用（指向不存在的技能/文件/路径） |
| 2 | `"$PY" "$TOOLS/verify-pack.py"` | 包完整性校验：frontmatter 规范（name/description/agent_created）、目录结构、路径写法（正斜杠） |
| 3 | `"$PY" "$TOOLS/skill-doctor.py" "$SKILLS" --fix-index` | 索引医生：检查各包健康状态，并重建 `skills/INDEX.md`（技能清单的唯一权威来源） |
| 4 | `"$PY" "$TOOLS/skill-compliance-audit.py"` | 合规审计：SKILL.md 行数（<500）、references TOC、包内是否混入 README/CHANGELOG 等违规文件 |

> 实际输出格式以脚本 `-h` / 源码为准；以上作用描述为整合验收时的实测口径。

## 使用时机

- **技能整合/搬迁/删除之后**：四件全跑，全绿才算收口
- **新增/修改 SKILL.md 之后**：至少跑 2（verify-pack）+ 3（doctor --fix-index）
- **打包交付前**：跑 1（ref-audit）确认无幽灵引用，再走本技能主流程

## 常见问题处理

| 症状 | 处理 |
|---|---|
| doctor 报某包缺 agent_created | 在该包 SKILL.md frontmatter 加 `agent_created: true`（缺失会导致技能静默不可用） |
| INDEX.md 与实际包不一致 | 重跑 `skill-doctor.py "$SKILLS" --fix-index` 重建 |
| ref-audit 报幽灵引用 | 修正指向：技能收编后旧名一律改为新落点（如「文档工具箱/references/HTML转Word报告.md」） |
| compliance 报 SKILL.md 超行 | 把正文细节下沉到 references/，入口只留路由表 |

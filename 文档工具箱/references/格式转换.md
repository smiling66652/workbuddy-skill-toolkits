# 二级：格式转换

**适用场景**：用户需要转换文档格式（PDF→Word/Markdown、Markdown→PDF/Word、Word→PDF等）

---

## 工具对比

| 转换方向 | 推荐工具 | 准确率 | 速度 | 备注 |
|-----------|---------|--------|------|------|
| PDF→Markdown | **MinerU** | ⭐⭐⭐⭐⭐ (97%) | 中 | 表格识别最准 |
| PDF→Word | **pdfkit-py** | ⭐⭐⭐ | 快 | 简单排版 |
| Markdown→PDF | **WeasyPrint** | ⭐⭐⭐⭐ | 中 | HTML/CSS渲染 |
| Markdown→Word | **pandoc** | ⭐⭐⭐⭐⭐ | 快 | 格式保留最好 |
| Word→PDF | **python-docx + reportlab** | ⭐⭐⭐⭐ | 中 | 需要Word |
| HTML→PDF | **WeasyPrint** | ⭐⭐⭐⭐⭐ | 快 | CSS支持好 |
| 任意→Markdown | **MarkItDown** | ⭐⭐⭐⭐ | 快 | 支持PPT/XLSX |

---

## 三级执行：PDF→Markdown（MinerU，推荐）

**触发词**：PDF转Markdown、提取PDF内容到MD

### 安装

```bash
pip install magic-pdf[full]
```

### 使用

```bash
# 命令行转换
magic-pdf -p input.pdf -o ./output

# 输出：./output/input.md + ./output/input/images/
```

---

## 三级执行：Markdown→Word/PDF（pandoc）

**触发词**：Markdown转Word、MD转PDF

### 安装

```bash
# 方法1：包管理器
# Windows: choco install pandoc
# Mac: brew install pandoc
# Linux: sudo apt install pandoc

# 方法2：下载安装包
# https://github.com/jgm/pandoc/releases
```

### 使用

```bash
# Markdown → Word
pandoc input.md -o output.docx

# Markdown → PDF（需要LaTeX或WeasyPrint）
pandoc input.md -o output.pdf

# Markdown → HTML
pandoc input.md -o output.html

# 带样式转换
pandoc input.md -o output.docx --reference-doc=template.docx

# 批量转换
for f in *.md; do pandoc "$f" -o "${f%.md}.docx"; done
```

## 三级执行：任意→Markdown（MarkItDown）

**触发词**：转Markdown、PPT转文字、Excel转MD

### 安装

```bash
pip install markitdown
```

### 使用

```python
from markitdown import MarkItDown

converter = MarkItDown()

# Word → Markdown
result = converter.convert("input.docx")
print(result.text_content)

# PowerPoint → Markdown
result = converter.convert("input.pptx")
print(result.text_content)

# Excel → Markdown
result = converter.convert("input.xlsx")
print(result.text_content)

# 图片 → Markdown（OCR）
result = converter.convert("image.png")
print(result.text_content)

# 音频 → Markdown（转录）
result = converter.convert("audio.mp3")
print(result.text_content)
```

## 三级执行：HTML→PDF（WeasyPrint）

**触发词**：网页转PDF、HTML生成PDF

### 安装

```bash
pip install weasyprint
```

### 使用

```python
from weasyprint import HTML, CSS

# 从HTML字符串生成
html_string = """
<html>
<head>
    <style>
        body { font-family: 'SimSun'; }
        h1 { color: navy; }
    </style>
</head>
<body>
    <h1>标题</h1>
    <p>正文内容</p>
</body>
</html>
"""
HTML(string=html_string).write_pdf("output.pdf")

# 从URL生成
HTML('https://example.com').write_pdf("webpage.pdf")

# 从文件生成
HTML(filename='input.html').write_pdf("output.pdf")

# 带CSS样式
css = CSS(string='@page { size: A4; margin: 2cm }')
HTML(filename='input.html').write_pdf("styled.pdf", stylesheets=[css])
```

## 三级执行：Word→PDF（python-docx + reportlab）

**触发词**：Word转PDF、DOCX转PDF

### 方法1：使用LibreOffice（推荐，免费）

```bash
# 安装LibreOffice
# 命令行转换
soffice --headless --convert-to pdf input.docx
```

### 方法2：使用Word COM（需要安装Microsoft Word）

```python
# 仅Windows，需要安装pywin32
import win32com.client

word = win32com.client.Dispatch("Word.Application")
doc = word.Documents.Open(r"C:\path\to\input.docx")
doc.SaveAs(r"C:\path\to\output.pdf", FileFormat=17)  # 17=PDF格式
doc.Close()
word.Quit()
```

### 方法3：使用Aspose.Words（商业库，免费试用）

```bash
pip install aspose-words
```

```python
import aspose.words as aw

doc = aw.Document("input.docx")
doc.save("output.pdf")
```

## 使用建议

1. **PDF→Markdown（表格多）** → MinerU（97%准确率）
2. **Markdown→Word/PDF** → pandoc（格式保留最好）
3. **任意格式→Markdown** → MarkItDown（支持PPT/XLSX/图片/音频）
4. **HTML→PDF** → WeasyPrint（CSS支持好）
5. **Word→PDF** → LibreOffice（免费）或 Microsoft Word（收费）
6. **批量转换** → 用循环 + 对应工具

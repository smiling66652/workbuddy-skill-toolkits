# DOCX 质量检查清单

## 结构检查

- 文件扩展名为 `.docx`，ZIP 包可读取。
- `[Content_Types].xml`、`_rels/.rels`、`word/document.xml` 存在且 XML 可解析。
- 标题层级连续，正文使用样式而非手工模拟。
- 列表使用真实编号定义，编号顺序正确。
- 表格数量、行列、合并单元格和重复表头符合预期。
- 图片、超链接、页眉页脚、脚注、批注和修订没有丢失或意外增加。
- 没有遗留占位符、调试文本、空白页和不需要的外部链接。

运行：

```bash
python3 scripts/inspect_docx.py output.docx
```

该脚本用于快速发现结构问题，不替代内容审阅或 Word 兼容性测试。

## 逐页视觉检查

创建新文档或进行布局相关修改后，渲染并检查每一页：

```bash
python3 scripts/render_docx.py output.docx --output-dir render
```

逐页确认：

- 没有文字裁切、重叠、乱码或缺失字形；
- 标题、正文、列表、表格和图片间距自然且统一；
- 表格未超出页面，单元格文字不贴边，跨页表头正确；
- 图片清晰、比例正确，题注与图片保持在合理位置；
- 页眉页脚、页码和节切换正确；
- 没有大面积异常留白、孤立标题或意外空白页；
- 最后一页完整，文档没有截断。

任何修复都必须重新渲染并复查受影响页面；涉及全局样式、页边距、字体或页眉页脚时，应重新检查全部页面。

## 内容检查

- 用户提供的事实、数字、名称、日期和引用保持准确。
- 修改范围与用户要求一致，没有擅自改变含义。
- 文档语言、语气、受众和用途一致。
- 目录、交叉引用和字段显示值已更新或已明确说明更新限制。
- 敏感内容、批注、修订和文档属性符合交付要求。

## 交付检查

- 最终文件名清晰，未覆盖原件（除非用户明确要求）。
- 最终文件可打开，大小非零，修改时间与本次任务一致。
- 只交付请求的文件；渲染图片和临时 PDF 默认不交付。
- 最终回复区分“结构检查通过”“视觉检查通过”和“未验证项”。

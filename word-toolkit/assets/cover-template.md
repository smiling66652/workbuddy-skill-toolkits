# 封面模板（Word 文档创作与美化）

标准封面由 `scripts/make_docx.py` 的 `cover()` 自动生成，结构如下：
（在 outline.json 的 `meta` 中填写，无需手写此页）

```
            ┌─────────────────────────────┐
            │                             │
            │       （上方留白约 120pt）     │
            │                             │
            │        文档主标题（26pt 深蓝） │
            │        副标题（14pt）         │
            │                             │
            │        作者    日期           │
            │                             │
            └─────────────────────────────┘
                （自动分页，进入正文）
```

## meta 字段

| 字段 | 说明 | 必填 |
|------|------|------|
| title | 文档主标题 | 是 |
| subtitle | 副标题 | 否 |
| author | 作者 / 单位 | 否 |
| date | 日期（建议 YYYY-MM-DD） | 否 |

## 变体建议

- **正式公文**：标题用方正小标宋，副标题省略，落款右对齐含单位与日期。
- **商业计划书**：主标题下加一句话定位（slogan）作为 subtitle。
- **学术论文**：副标题处放「学校 / 院系 / 导师」信息。

> 封面后自动插入分页符，正文从新页开始。

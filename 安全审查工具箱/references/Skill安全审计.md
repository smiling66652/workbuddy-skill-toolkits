# 二级：Skill安全审计

**适用场景**：安装Skill前安全审计、检查Skill权限和潜在风险

---

## 工具对比

| 工具 | 审计深度 | 速度 | 推荐场景 |
|------|---------|------|------------|
| **腾讯云鼎实验室** | ⭐⭐⭐⭐⭐ | 中 | Skill安装前审计（推荐） |
| **skill-vetter** | ⭐⭐⭐ | 快 | 快速检查 |
| **人工审查** | ⭐⭐⭐⭐⭐ | 慢 | 高风险Skill |

---

## 三级执行：腾讯云鼎实验室（推荐）

**触发词**：Skill安全审计、安装前检查、云鼎审计

### 审计流程

```
1. 静态分析：
   - 检查 SKILL.md 中的危险操作
   - 检查脚本文件中的敏感命令
   - 检查依赖包是否有已知漏洞

2. 权限分析：
   - 检查 Skill 是否需要网络访问
   - 检查 Skill 是否需要文件系统访问
   - 检查 Skill 是否需要环境变量（API Key）

3. 行为分析：
   - 在沙箱环境中运行 Skill
   - 观察网络连接
   - 观察文件操作

4. 报告生成：
   - 生成安全审计报告
   - 标注风险等级（P0/P1/P2）
   - 给出修复建议
```

### 风险等级定义

- **P0（严重）**：恶意代码、数据泄露、权限提升
- **P1（高危）**：敏感信息收集、不安全网络通信
- **P2（安全）**：代码质量问题、文档不清晰

---

## 三级执行：skill-vetter（快速检查）

**触发词**：快速检查Skill、vetter检查

### 使用

```bash
# 安装 skill-vetter
pip install skill-vetter

# 检查单个 Skill
skill-vetter check path/to/skill/

# 批量检查
skill-vetter batch-check path/to/skills/
```

---

## 使用建议

1. **安装前必查** → 腾讯云鼎实验室（全面审计）
2. **快速检查** → skill-vetter
3. **高风险Skill** → 人工审查
4. **定期审查** → 每月审查已安装的Skill
5. **权限最小化** → 只授予Skill所需的最小权限

---

## 注意事项

- **API Key保护**：检查Skill是否会泄露API Key
- **网络隔离**：在沙箱中测试网络访问
- **文件系统隔离**：检查Skill是否会访问敏感文件
- **定期更新**：依赖包可能有新漏洞，定期更新

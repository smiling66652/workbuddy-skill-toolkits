# 二级：通用安全审查

**适用场景**：用户需要对Skill进行通用的安全检测，不特定于某个平台或工具。

---

## 三级执行：skill-vetter 审查

### 安装 skill-vetter

```bash
# skill-vetter通常随WorkBuddy安装
# 如果没有，手动安装：
workbuddy skill install skill-vetter
```

### 使用 skill-vetter 审查

```bash
# 审查指定Skill
skill-vetter check ~/.workbuddy/skills/skill名称/

# 输出详细报告
skill-vetter check ~/.workbuddy/skills/skill名称/ --verbose

# 自动修复低风险问题
skill-vetter check ~/.workbuddy/skills/skill名称/ --auto-fix
```

---

## 三级执行：skill-scanner 扫描

### 安装 skill-scanner

```bash
# skill-scanner通常随WorkBuddy安装
# 如果没有，手动安装：
workbuddy skill install skill-scanner
```

### 使用 skill-scanner 扫描

```bash
# 扫描Skill目录
skill-scanner scan ~/.workbuddy/skills/skill名称/

# 深度扫描（包括依赖）
skill-scanner scan ~/.workbuddy/skills/skill名称/ --deep

# 输出JSON格式
skill-scanner scan ~/.workbuddy/skills/skill名称/ --format json --output scan.json
```

---

## 审查项目清单

| 审查项 | 说明 | 风险等级 |
|-------|------|---------|
| **权限申请** | Skill是否申请了不必要的权限 | P1 |
| **网络访问** | 是否有未声明的网络访问 | P1 |
| **文件操作** | 是否读写敏感文件路径 | P1 |
| **命令执行** | 是否执行系统命令 | P2 |
| **依赖安全** | 依赖包是否有已知漏洞 | P2 |
| **数据收集** | 是否收集用户数据 | P2 |
| **代码混淆** | 是否存在代码混淆或加密 | P3 |
| **文档完整性** | SKILL.md是否完整 | P4 |

---

## 自动审查流程

```
开始审查
  ├── 1. 静态分析（代码模式匹配）
  │     ├── 检测危险函数调用
  │     ├── 检测硬编码密钥
  │     └── 检测可疑网络请求
  ├── 2. 依赖分析
  │     ├── 检查依赖版本
  │     └── 查询CVE数据库
  ├── 3. 权限分析
  │     ├── 对比申请的权限和实际使用
  │     └── 检测权限提升尝试
  └── 4. 生成报告
        ├── 风险等级评定
        ├── 问题详情列表
        └── 修复建议
```

## 与其他审查工具的关系

| 工具 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| **云鼎实验室** | WorkBuddy Skill安装前 | 深度审查，沙箱隔离 | 仅适用于WorkBuddy Skill |
| **A.I.G** | 第三方Skill | 行为分析，风险评分 | 需要安装独立工具 |
| **skill-vetter** | 通用审查 | 轻量，快速 | 深度不如专用工具 |
| **skill-scanner** | 通用扫描 | 支持深度扫描 | 可能产生误报 |

**推荐组合使用**：
1. 安装前 → 云鼎实验室（必选）
2. 第三方Skill → A.I.G（推荐）
3. 定期检查 → skill-vetter + skill-scanner（可选）

---

## 注意事项

1. **误报处理** — 如果确认是误报，可以将文件路径加入白名单
2. **定期重新审查** — Skill更新或依赖变更后需要重新审查
3. **结合人工复核** — 自动化工具不能完全替代人工审查
4. **保留审查记录** — 将审查报告存档，便于追溯

---

## 故障排查

| 问题 | 解决方案 |
|------|-----------|
| skill-vetter未找到 | `workbuddy skill install skill-vetter` |
| skill-scanner未找到 | `workbuddy skill install skill-scanner` |
| 扫描超时 | 增加`--timeout`参数或减少扫描范围 |
| 误报率高 | 更新审查规则或提交误报报告 |
| 依赖分析失败 | 检查网络连接或手动指定依赖版本 |

# 微信小程序项目结构指南

## 基础结构 #

```
├── app.js                 # 小程序逻辑（App() 注册）
├── app.json               # 小程序配置（页面路由、窗口样式、tabBar）
├── app.wxss               # 全局样式（所有页面共享）
├── project.config.json     # 项目配置（编译设置、AppID）
├── sitemap.json           # 搜索引擎配置（微信搜索）
├── pages/                 # 页面目录
│   └── index/
│       ├── index.js        # 页面逻辑
│       ├── index.json      # 页面配置
│       ├── index.wxml      # 页面模板
│       └── index.wxss     # 页面样式
├── components/           # 自定义组件目录
│   └── my-component/
│       ├── my-component.js    # 组件逻辑
│       ├── my-component.json  # 组件配置
│       ├── my-component.wxml  # 组件模板
│       └── my-component.wxss  # 组件样式
├── cloudfunctions/       # 云函数目录（如果使用云开发）
│   └── addTodo/
│       └── index.js
├── miniprogram_npm/      # npm 包构建目录
└── references/           # 参考文档目录
```

## app.js（小程序逻辑） #

```javascript
// app.js
App({
  onLaunch(options) {
    // 小程序初始化（全局只触发一次）
    console.log('小程序启动', options);
    
    // 获取用户信息
    const userInfo = wx.getStorageSync('userInfo');
    if (userInfo) {
      this.globalData.userInfo = userInfo;
    }
  },
  onShow(options) {
    // 小程序从前台进入前台
    console.log('小程序显示', options);
  },
  onHide() {
    // 小程序从前台进入后台
    console.log('小程序隐藏');
  },
  globalData: {
    // 全局数据（所有页面共享）
    userInfo: null,
    baseUrl: 'https://api.example.com'
  }
})
```

## pages/index/index.js（页面逻辑） #

```javascript
// pages/index/index.js
Page({
  data: {
    // 页面数据
    message: 'Hello World',
    list: []
  },
  onLoad(options) {
    // 页面加载（一个页面只调用一次）
    console.log('页面加载', options);
  },
  onShow() {
    // 页面显示（每次打开页面都调用）
    console.log('页面显示');
  },
  onReady() {
    // 页面初次渲染完成（一个页面只调用一次）
    console.log('页面就绪');
  },
  onHide() {
    // 页面隐藏（进入后台或其他页面）
    console.log('页面隐藏');
  },
  onUnload() {
    // 页面卸载（redirectTo 或 navigateBack）
    console.log('页面卸载');
  },
  onPullDownRefresh() {
    // 下拉刷新
    wx.showNavigationBarLoading();
    setTimeout(() => {
      wx.hideNavigationBarLoading();
      wx.stopPullDownRefresh();
    }, 1000);
  },
  onReachBottom() {
    // 上拉加载更多
    console.log('加载更多');
  },
  onShareAppMessage() {
    // 分享给朋友
    return {
      title: '分享标题',
      path: '/pages/index/index'
    };
  },
  // 自定义方法
  handleTap(e) {
    console.log(e);
    this.setData({
      message: 'Hello WorkBuddy'
    });
  }
})
```

## components/my-component/my-component.js（组件逻辑） #

```javascript
// components/my-component/my-component.js
Component({
  properties: {
    // 父 → 子（属性）
    prop: {
      type: String,
      value: 'default value'
    }
  },
  data: {
    // 组件内部数据
    internalData: 'internal'
  },
  methods: {
    // 组件方法
    customMethod() {
      this.setData({
        internalData: 'updated'
      });
    }
  },
  lifetimes: {
    // 组件生命周期
    attached() {
      console.log('组件 attached');
    },
    detached() {
      console.log('组件 detached');
    }
  },
  pageLifetimes: {
    // 组件所在页面的生命周期
    show() {
      console.log('页面显示');
    },
    hide() {
      console.log('页面隐藏');
    }
  }
})
```

## 故障排查 #

| 问题 | 解决方案 |
|------|-----------|
| 页面不显示 | 检查 `app.json` 的 `pages` 字段是否配置了页面路径 |
| 数据不更新 | 检查是否使用 `this.setData({})` 更新数据 |
| 事件不触发 | 检查事件绑定是否正确（`bindtap` vs `catchtap`） |
| 组件不显示 | 检查 `json` 中的 `usingComponents` 是否配置正确 |
| API 调用失败 | 检查 API 是否需要配置域名白名单（微信公众平台 → 开发管理 → 开发设置 → 服务器域名） |

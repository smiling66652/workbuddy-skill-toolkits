# 微信小程序部署上线指南

## 预览 #

### 使用微信开发者工具预览 #

1. 打开微信开发者工具
2. 点击顶部工具栏的 **预览** 按钮
3. 使用微信扫描二维码
4. 在手机上预览小程序

### 使用命令行预览 #

```bash
# ⚠️ 2026-09-15 核实：npm 上不存在 wechat-devtools-cli（404）
# 两条真实可用的路径：
#   A. 微信开发者工具自带的 CLI（无需 npm 安装）
#      安装开发者工具后，在「设置 → 安全设置」开启服务端口，然后：
#      "<开发者工具安装目录>/cli.bat" preview --project /path/to/project
#   B. 官方 npm 包 miniprogram-ci（已核实存在，需 appid + 上传密钥）
npm install -g miniprogram-ci
npx miniprogram-ci preview --pp ./ --pkp ./private.key --appid <你的appid>
```

## 真机调试 #

### 使用微信开发者工具真机调试 #

1. 打开微信开发者工具
2. 点击顶部工具栏的 **真机调试** 按钮
3. 使用微信扫描二维码
4. 在手机上调试小程序

### 使用 VS Code 调试 #

1. 安装 **微信小程序开发助手** 插件
2. 打开小程序项目
3. 按 `F5` 启动调试
4. 选择 **真机调试**

---

## 上传代码 #

### 使用微信开发者工具上传 #

1. 打开微信开发者工具
2. 点击顶部工具栏的 **上传** 按钮
3. 填写 **版本号** 和 **项目备注**
4. 点击 **上传**

### 使用命令行上传 #

```bash
# ⚠️ 2026-09-15 核实：wechat-devtools-cli 不存在，改用官方 miniprogram-ci
npm install -g miniprogram-ci
npx miniprogram-ci upload --pp ./ --pkp ./private.key --appid <你的appid> \
  --uv 1.0.0 --ud "初始版本"
```

## 提交审核 #

### 登录微信公众平台 #

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)
2. 使用微信扫码登录
3. 进入 **开发管理** → **开发版本**

### 提交审核 #

1. 点击 **提交审核** 按钮
2. 填写 **审核信息**（如：功能页面、测试账号等）
3. 点击 **提交审核**

### 审核状态 #

| 状态 | 说明 |
|------|------|
| 审核中 | 等待微信团队审核 |
| 审核通过 | 可以发布上线 |
| 审核失败 | 需要根据反馈修改代码，重新上传 |

---

## 发布 #

### 发布上线 #

1. 登录微信公众平台
2. 进入 **开发管理** → **审核版本**
3. 点击 **发布** 按钮
4. 确认发布

### 发布注意事项 #

1. 发布后，用户需要 **删除小程序** 或 **清除缓存** 才能看到最新版本
2. 发布后，不能立即搜索到小程序，需要等待 **微信索引**

---

## 版本管理 #

### 查看版本历史 #

1. 登录微信公众平台
2. 进入 **开发管理** → **开发版本**
3. 可以查看所有上传的版本

### 回滚版本 #

1. 登录微信公众平台
2. 进入 **开发管理** → **线上版本**
3. 点击 **回滚** 按钮
4. 选择要回滚到的版本

---

## 数据监控 #

### 查看访问数据 #

1. 登录微信公众平台
2. 进入 **数据分析** → **访问分析**
3. 可以查看 **访问人数**、**访问次数**、**停留时长** 等

### 查看错误日志 #

1. 登录微信公众平台
2. 进入 **开发管理** → **错误日志**
3. 可以查看 **JS 错误**、**API 错误** 等

---

## 故障排查 #

| 问题 | 解决方案 |
|------|-----------|
| 预览失败 | 检查微信开发者工具是否正常启动 |
| 上传失败 | 检查是否登录了微信开发者工具 |
| 审核被拒 | 根据微信反馈修改代码，重新上传 |
| 发布后看不到 | 等待微信索引，或让用户删除小程序重新进入 |
| 数据不准确 | 检查是否配置了正确的统计参数 |

# 文献综述

> 综述的本质不是「罗列论文」，而是**建立分类体系 + 逐类对比 + 指出研究空白**。评分老师看的是你对领域的判断，不是你读了多少篇。

---

## 1. 结构化写法（漏斗结构，六段式）

按这个顺序写，天然有逻辑：

1. **引言**：研究背景、为什么重要（如农业采收/食品分拣对无损抓取的需求）、综述范围与边界。
2. **分类体系**：用一条贯穿始终的维度把文献切开（见第 2 节）。
3. **逐类对比**：每一类讲原理、代表工作、性能，并落到**对比表**。
4. **共性难题**：跨类都解决不了的硬骨头。
5. **研究空白（gap）与趋势**：哪些没人做、哪些矛盾、未来往哪走。
6. **结语**：一句话总结现状 + 你的判断。

> 不要把第 3、4、5 节混成一锅粥。先「分述」，再「归纳难题」，最后「找空白」。

---

## 2. 分类体系怎么搭（综述质量的核心）

**一条原则：选一个维度贯穿全篇，不要中途换维度。**

| 分类维度 | 适合场景 | 例子（柔性抓取） |
|---|---|---|
| **按技术路线分** | 方法型综述，最常见 | 柔性末端执行器（软体/绳驱/变刚度）｜力控策略（阻抗/导纳/混合）｜传感反馈（视觉/触觉/力） |
| **按被抓对象分** | 应用型综述 | 果蔬（番茄）｜蛋类（鸡蛋）｜通用易变形体 |
| **按问题分** | 问题导向、偏分析 | 接触建模难｜形变感知难｜力控稳定难 |
| **按年代分** | 展示演进，常作补充 | 2010 前刚性夹爪 → 2015 后软体兴起 → 2020 后学习+柔抓 |

**选型建议**：
- 写「柔性抓取技术综述」→ 用**技术路线**分（最稳、最显专业）。
- 写「番茄/鸡蛋无损抓取」→ 用**对象 + 技术路线**组合（对象作一级，路线作二级）。
- 年代分**不要单独用**，放进引言或每类开头做演进说明即可。

## 3. 对比表格模板（直接套用）

这是综述里最能体现功力的部分，务必有。复制下面骨架：

```markdown
| 方法/路线 | 核心原理 | 抓取精度/损伤率 | 适用对象 | 主要局限 | 出处(DOI) |
|---|---|---|---|---|---|
| 软体气动夹爪 | 气压驱动柔性腔体包络 | 损伤率低，定位精度中 | 番茄、蛋类 | 出力小、建模难 | 10.xxxx/xxxxx |
| 绳驱柔性手 | 绳索牵引多关节 | 精度较高 | 中等刚度物体 | 结构复杂、成本高 | 10.xxxx/xxxxx |
| 可变刚度末端 | 颗粒阻塞/低熔点合金调刚度 | 可调，适应性好 | 异形易损件 | 响应慢 | 10.xxxx/xxxxx |
| 阻抗/力控策略 | 调节末端等效刚度-阻尼 | 接触力可控、损伤低 | 通用 | 参数整定难 | 10.xxxx/xxxxx |
| 视觉/触觉反馈 | 闭环修正抓取力 | 自适应好 | 未知物体 | 传感噪声、算力 | 10.xxxx/xxxxx |
```

> 每一行**最后必须填 DOI/出处**，没有出处的行就是「未验证」，宁可删掉。数字（损伤率、精度）要加粗，且来自论文原文。

## 4. 如何找研究空白（gap）

gap 是决定综述档次的。三种可靠来源：

1. **汇总每篇的 future work**：几乎每篇结尾都写「未来将…」，把这些句子收集起来，重合度高的就是真空白。
2. **找矛盾结论**：论文 A 说「方法 X 在易损物上损伤率最低」，论文 B 在相同对象上得出相反结论 → 这是值得深挖的矛盾/边界条件问题。
3. **被反复提及但未解决**：如「实时形变感知难」「软体动力学建模不准」「阻抗参数自适应整定缺理论」。出现 3 篇以上且都「尚未解决」= 真 gap。

> 写 gap 时同样要**附出处**，指出「是谁、在哪篇提出了这个未解问题」。

---

## 5. 常见坑（务必避开）

| 坑 | 表现 | 正确做法 |
|---|---|---|
| 只罗列不评述 | 「文献[1]做了X，[2]做了Y…」然后没了 | 每类结尾给**评价**：优劣、适用边界 |
| 引二手文献 | 引「某综述说 Hogan 提出了阻抗控制」 | 追到 Hogan 1985 原始论文并引原文 |
| 分类维度混乱 | 一段按方法分、下一段莫名按年代 | 固定一条维度贯穿，年代只作补充 |
| 缺对比表 | 全文纯文字 | 必有第 3 节那种对比表 |
| 不写 gap | 结尾只说「研究很多」 | 必须有第 5 节，附出处 |
| 数字无来源 | 「损伤率降低到很低」 | 给具体论文里的**具体数值+DOI** |

## 6. 针对「机械臂柔性抓取」的综述大纲示例

> 适用：课程小组项目申请书 / 文献综述作业。按技术路线分类。

```
0. 引言
   - 背景：农业采收(番茄)、食品分拣(鸡蛋)对无损抓取的需求；刚性夹爪易伤易损物
   - 范围：聚焦「柔性末端 + 力/阻抗控制 + 感知反馈」三层
1. 易损对象抓取难点
   - 低刚度、易形变、表面易伤；接触力-形变耦合难建模
2. 分类体系（按技术路线）
   2.1 柔性末端执行器
       - 软体气动 / 绳驱 / 可变刚度（颗粒阻塞、低熔点合金）
   2.2 力控策略
       - 阻抗控制 / 导纳控制 / 混合力位控制
   2.3 感知反馈
       - 视觉伺服 / 触觉阵列 / 力传感器闭环
3. 逐类对比表（套用第3节模板，每行带DOI）
4. 共性难题
   - 接触-形变耦合建模、实时形变感知、阻抗参数整定无通用理论
5. 研究空白与趋势
   - 多模态感知融合、自适应/学习式阻抗、面向番茄/鸡蛋的专用柔抓系统缺乏
6. 结语
   - 现状判断 + 本项目切入点（如：结合可变刚度与自适应阻抗，针对番茄采收）
```

> 把第 6 节的「本项目切入点」直接喂给你的项目申请书即可形成逻辑链条。

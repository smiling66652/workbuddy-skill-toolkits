# 论文检索

> 检索总原则：**先用英文开源库（arXiv / Semantic Scholar）抓核心论文与引文关系，再用中文库（CNKI）补国内进展**；订阅库（IEEE / ScienceDirect）走校园网直连拿全文。
> 所有 curl 命令都要带 `--ssl-no-revoke`（校园网证书吊销检查坑，参见 SKILL.md 环境提示）。

---

## 1. 中文检索词 ↔ 英文检索词对照

你是中文母语，但机器人/控制领域好论文几乎都在英文库。先建好对照表，中英文库各搜一遍，避免漏检。

| 中文概念 | 英文检索词（可组合） |
|---|---|
| 柔性抓取 / 软体抓取 | `compliant grasping` / `soft grasping` / `deformable object grasping` |
| 柔性末端执行器 | `soft gripper` / `compliant end-effector` / `soft robotic gripper` |
| 阻抗控制 | `impedance control` / `admittance control` / `compliant control` |
| 力控制 / 力位混合 | `force control` / `hybrid position-force control` |
| 易损对象（番茄/鸡蛋） | `fragile object handling` / `robust fruit picking` / `egg grasping` |
| 可变刚度 | `variable stiffness` / `stiffness tuning` |
| 触觉 / 形变感知 | `tactile sensing` / `deformation perception` / `vision-based grasp` |
| 农业采收 | `agricultural harvesting robot` / `crop harvesting` |

> 组合技巧：核心对象 + 方法，例如 `"soft gripper" AND "impedance control"`、`"compliant grasping" AND "fragile"`。

## 2. 按数据库分节

> **2026-09-10 本机实测排序（先看这个）**：
> **OpenAlex ✅ > Crossref ✅ > HuggingFace Papers ✅ > DOAJ ✅ > ChinaXiv ✅ > Semantic Scholar ⚠️限流 > CNKI / IEEE / Elsevier（需校园订阅）> arXiv ❌ 不可达**。
> 排在前面的优先用，别在不可达的源上浪费时间。

### 2.0.1 拿全文的四步策略（arXiv 不可用时）

按序尝试，不要跳步：

1. **OpenAlex 拿 OA 直链**（实测有效）——`select` 里带上 `open_access`：
   ```bash
   curl -s --ssl-no-revoke \
     "https://api.openalex.org/works?search=robotic%20grasping%20fragile%20impedance&per-page=6&select=title,publication_year,cited_by_count,doi,open_access"
   ```
   返回中 `open_access.is_oa=true` 的条目，`open_access.oa_url` 即全文直链。
   实测：检索「robotic grasping fragile object impedance control」命中 **678** 条，其中 *Soft Robotic Grippers*(2018, 被引 1932)、*A Century of Robotic Hands*(2019, 被引 334) 等均为 OA。
   ⚠️ 出版商直链（如 `onlinelibrary.wiley.com`）可能返回 **403**——那是 IP 墙，不是链接失效，**需校园网 IP / CARSI**，见第 3 步。

2. **换正式发表版本**——arXiv 预印本大多最终发表在期刊/会议。用 OpenAlex 拿到 DOI 后走订阅库，往往比找预印本更省事。

3. **走合工大官方渠道**（需信息门户账号 = 学号，初始密码身份证后六位）：
   - **WebVPN**：`https://webvpn.hfut.edu.cn` → CAS 统一认证 → 点「图书馆资源」。**这是唯一有可能改变出口 IP 的官方途径**，到校后/连校园网时实测一次 `arxiv.org`，通了就优先用它。
   - **CARSI**：`https://www.carsi.edu.cn` 成员列表选「合肥工业大学」→ 信息门户登录。已确认覆盖 **中国知网、Elsevier ScienceDirect、IEEE、Springer、RSC、EBSCO**。**注意：CARSI 资源列表里没有 arXiv**，它解决的是订阅库而非预印本。

4. **图书馆文献传递**（兜底，正规且几乎万能）——前 3 步都拿不到的全文，到图书馆官网提交「馆际互借/文献传递」申请，馆员代下，通常几小时到 1 个工作日。写综述时少量关键文献走这条最划算。

> **一句话**：发现文献用 **OpenAlex + HuggingFace Papers**（都能拿到 arXiv 元数据），拿全文靠 **OA 直链 → 学校订阅库 → 文献传递** 三级漏斗。不要执着于直连 arXiv。

### 2.0 OpenAlex（**首选**：免费、无需 key、已实测可用）

- **适用场景**：通用学术检索，覆盖论文 / 作者 / 机构 / 引用关系。**收录 arXiv 预印本元数据**，是 arXiv 不可用时的最佳替代。
- **API 端点**：`https://api.openalex.org/works`
- **实测通过的调用（2026-09-10 本机直连）**：

  ```bash
  curl -s --ssl-no-revoke \
    "https://api.openalex.org/works?search=soft%20grasping%20impedance&per-page=5&select=id,title,publication_year,cited_by_count,doi"
  ```

  真实返回：`meta.count=4373`，结果含 `title` / `publication_year` / `cited_by_count` / `doi`，
  例如 *Soft robotic glove for combined assistance and at-home rehabilitation*（2014，**被引 1621**）。

- **常用参数**：`search=` 全文检索、`filter=` 精确过滤、`per-page=`（≤200）、`select=` 指定返回字段、`sort=cited_by_count:desc` 按引用量排序。官方建议在 URL 末尾加 `&mailto=你的邮箱` 进入「礼貌池」，速率更稳。
- **滚雪球**：每条记录自带 `referenced_works` 数组，可直接做 backward / forward 引文追踪，不用额外接口。
- **注意**：检索词里的空格要写成 `%20`。

### 2.1 arXiv（⚠️ 当前网络不可达，语法仅供参考）

- **适用场景**：追最新成果（机器人 cs.RO 更新极快）、找综述草稿、免费全文 PDF。
- **API 端点**：`http://export.arxiv.org/api/query`
- **检索语法 `search_query`**（核心字段）：

  | 前缀 | 含义 | 示例 |
  |---|---|---|
  | `all:` | 全字段 | `all:"compliant grasping"` |
  | `ti:` | 标题 | `ti:impedance` |
  | `au:` | 作者 | `au:Hogan` |
  | `abs:` | 摘要 | `abs:"soft gripper"` |
  | `cat:` | 分类 | `cat:cs.RO` |
  | 逻辑 | `AND` / `OR` / `ANDNOT` | `ti:grasp AND cat:cs.RO` |
  | 分组 | `()` | `(ti:grasp OR ti:gripper) AND cat:cs.RO` |

  其它参数：`start=0`（偏移）、`max_results=10`（条数）、`sortBy=submittedDate|relevance`、`sortOrder=descending|ascending`。

- **可直接复制的命令**：

  ```bash
  # 检索「柔性抓取 + 阻抗控制」最新 10 篇（cs.RO）
  curl -s --ssl-no-revoke "http://export.arxiv.org/api/query?search_query=%28ti:%22compliant%20grasping%22%20OR%20ti:%22soft%20grasp%22%29%20AND%20cat:cs.RO&start=0&max_results=10&sortBy=submittedDate&sortOrder=descending" -o arxiv_result.xml

  # 取标题与摘要（用 python 简单解析 Atom XML）
  "C:/Users/Matebook/.workbuddy/binaries/python/versions/3.13.12/python.exe" - <<'PY'
  import xml.etree.ElementTree as ET
  ns={'a':'http://www.w3.org/2005/Atom'}
  t=ET.parse('arxiv_result.xml').getroot()
  for e in t.findall('a:entry',ns):
      print('TITLE :', e.find('a:title',ns).text.strip().replace('\n',' '))
      print('PUBL  :', e.find('a:published',ns).text)
      idu=e.find('a:id',ns).text
      print('URL   :', idu)
      print('ABSTRACT:', (e.find('a:summary',ns).text or '').strip()[:240])
      print('-'*60)
  PY
  ```

- **结果字段含义**（返回 Atom XML）：`entry` 每条论文；`title` 标题；`summary` 摘要；`published` 提交日期；`author/name` 作者；`id` 即 arXiv 链接（含 abs 编号）；`arxiv:doi`（若已正式发表会有 DOI）；`link` 含 PDF 地址（`title="pdf"` 那个）。
- **限流与注意**：官方建议请求间隔 ≥ 3 秒，勿并发刷；返回是 XML 不是 JSON，用上面 python 片段解析。
- **实测状态（2026-09-10 在用户本机校园网实测）**：❌ **当前网络不可达，不要指望它**。完整诊断：

  | 排查步骤 | 结果 |
  |---|---|
  | `curl http/https export.arxiv.org` | **HTTP 000** |
  | `nslookup export.arxiv.org`（本地 DNS） | 解析到 **`10.202.22.17`（内网地址）** → **校园网 DNS 劫持** |
  | `nslookup export.arxiv.org 8.8.8.8`（公共 DNS） | 真实 IP：`151.101.131.42` / `151.101.3.42` / `151.101.195.42`（Fastly CDN） |
  | `curl --resolve` 强制指向上述真实 IP | **仍 HTTP 000**（三个 IP 全试过） |
  | 走本地代理 `127.0.0.1:10808` | **仍 HTTP 000** |
  | 对照：`api.github.com` / `api.crossref.org` / `api.openalex.org` | **均正常**（200 / 有数据） → 证明不是断网 |

  **结论**：不只是 DNS 污染，**出口防火墙把 Fastly CDN 整个网段封了**，当前网络环境下无解。

- **怎么办**：
  1. 用 **OpenAlex**（见 2.0）或 **Crossref** 替代——两者都收录 arXiv 元数据，能覆盖绝大部分检索需求；
  2. 只要 arXiv 的 PDF 全文，可换手机热点 / 校外网络 / 学校图书馆代理再下；
  3. 本节 API 语法本身是对的（依据 [arXiv 官方 API 文档](https://info.arxiv.org/help/api/user-manual.html) 核对），换到可达的网络可直接用。

### 2.2 Semantic Scholar（开放免费，强在引文图谱）

- **适用场景**：按主题搜论文、**找「谁引用了这篇」(forward) 和「它引用了谁」(backward)**、看被引数、批量拿元数据。
- **API 端点**：`https://api.semanticscholar.org/graph/v1/paper/search`
- **可直接复制的命令**：

  ```bash
  # 主题搜索（字段按需增减）
  curl -s --ssl-no-revoke -H "User-Agent: research/1.0" \
    "https://api.semanticscholar.org/graph/v1/paper/search?query=soft%20grasping%20robot&limit=5&fields=title,year,authors,externalIds,citationCount" \
    -o s2_search.json

  # 拿到 paperId 后，查「它引用了谁」(references) 与「谁引用了它」(citations)
  # 用 DOI 直接定位 paperId：
  curl -s --ssl-no-revoke "https://api.semanticscholar.org/graph/v1/paper/DOI:10.1109/TRO.2021.xxxxx/citations?fields=title,year,citationCount" -o s2_cited_by.json
  ```

- **结果字段含义**：`data[]` 数组，每项 `paperId`（后续查引文用）、`title`、`year`、`authors[]`、`externalIds.DOI`、`citationCount`（被引数）。`/paper/{id}/citations` 返回引用了它的论文；`/paper/{id}/references` 返回它引用的论文——**这正是雪球法的 API 实现**。
- **限流与注意**：**匿名限流很严（约 1 请求/秒，且共享 IP 易 429）**。撰写时实测即返回 `429 Too Many Requests`。解法：① 申请**免费 API key**（https://www.semanticscholar.org/product/api#api-key-form），请求头带 `x-api-key:`；② 降低频率、加 `sleep 1`；③ 需要大批量时用其官方 Bulk Data 下载。
- **撰写时实测状态**：✅ 接口**可达**（实测返回 429 = 服务器正常响应，仅限流），命令语法正确，建议配 API key 后使用。

### 2.3 CNKI 知网（中文库，需校园网/CARSI）

- **适用场景**：中文核心、硕博论文、国内课题组进展、中文综述。
- **现实**：知网**没有公开免费 API**，不要编造 endpoint。正路是**走学校 CARSI / 校园网 web 端**。
- **操作策略**：
  1. 学校图书馆「数据库导航」→ 中国知网（CARSI 登录，校外也能用）。
  2. **高级检索**用检索式：`SU='柔性抓取'`、`SU='阻抗控制'`、`FT='软体夹持器'`（SU=主题，FT=全文，AU=作者，AF=机构填「合肥工业大学」可找本校相关）。
  3. 勾选结果 → **导出与分析 → 导出文献** → 选 **GB/T 7714-2015** 格式（知网原生支持，直接用）；如需 BibTeX，用 Zotero  connectors 抓网页或用 `引用管理.md` 的 DOI 转 BibTeX（中文 DOI 同样适用）。
  4. 硕士/博士论文是「柔性抓取」「农业机器人」方向极佳的中文一手材料，务必纳入。
- **注意**：知网导出的是 GB/T 7714 文本，与英文 BibTeX 体系不同，见 `引用管理.md` 的规范对照。

### 2.4 IEEE Xplore（订阅库，校园网直连）

- **适用场景**：电气/机器人/自动化顶会（ICRA/IROS）与期刊（TRO/RA-L）几乎是必检库。
- **官方 API**：`https://ieeexploreapi.ieee.org/gateway/...`（如 `/search/articles`、`/article/<article_number>`）。

- **策略**：无 key 时直接**校园网 web 端**高级检索，检索式 `(("compliant grasping") AND ("impedance control"))`，勾选后用「下载引文」导出 RIS/BibTeX 进 Zotero。
- **撰写时实测状态**：❌ 未实测（需 key + 校园订阅），按官方端点与 web 策略操作。

### 2.5 ScienceDirect / Elsevier（订阅库，校园网直连）

### 2.6 Google Scholar（常被墙，备降级）

- **问题**：极易触发验证码（「unusual traffic」），且本环境实测 `HTTP 000` 不可达。
- **降级方案（按推荐顺序）**：
  1. **Semantic Scholar** 替代 forward/backward 引文追踪（见 2.2，最稳）。
  2. **百度学术**（国内可达，scholar.baidu.com）——能查中英文、导出引用、看引文数。

  5. 若必须用 GS：用校园网 + 浏览器手动，或 Python `scholarly` 库（需能访问 GS，必要时配代理），**不要依赖自动高频抓取**，会被封。

## 3. 检索策略方法（比单条命令更重要）

### 3.1 雪球法（Snowballing）
- **Backward（向后滚）**：从 1 篇种子论文的 `references` 找更早的相关工作 → 用 S2 `/paper/{id}/references` 或论文末参考文献列表。
- **Forward（向前滚）**：找「后来谁引用了这篇」→ 用 S2 `/paper/{id}/citations`，或用 CNKI/IEEE 的「引证文献」功能。
- 滚 2~3 轮，基本能网住一个子领域的核心文献。

### 3.2 选种子
- 先搜 2~3 篇**高被引综述**（review）作起点，综述的参考文献本身就是现成的 backward 雪球。
- 用 S2 的 `citationCount` 排序挑高被引原始论文。

### 3.3 关键词迭代
- 第一轮宽：`"soft gripper"` → 看结果里的高频词 → 第二轮加限定：`"soft gripper" AND "impedance control"` → 再窄到对象：`AND "fragile"` / `AND "fruit"`。

## 4. 针对「机械臂柔性抓取 / 阻抗控制」的具体建议

**起步检索式（直接可用）：**

| 目标 | 在哪儿搜 | 检索式 |
|---|---|---|
| 柔性抓取综述 | arXiv / CNKI | `all:"compliant grasping" review` ；知网 `SU='柔性抓取' AND SU='综述'` |
| 软体夹持器 | arXiv cs.RO | `(ti:"soft gripper" OR ti:"soft robotic gripper") AND cat:cs.RO` |
| 阻抗控制抓易损物 | IEEE / S2 | `("impedance control") AND ("compliant grasping" OR "fragile object")` |
| 番茄/果蔬采收 | CNKI / ScienceDirect | 知网 `SU='番茄' AND SU='采摘机器人'`；SD `("fruit" OR "tomato") AND ("robotic harvesting")` |
| 鸡蛋无损抓取 | S2 / CNKI | `"egg grasping" OR "egg handling robot"` |
| 可变刚度末端 | arXiv / IEEE | `"variable stiffness" AND "gripper"` |

**推荐起步动作（按顺序）：**
1. S2 搜 `"soft grasping robot"` 拿 top 10 高被引 → 进 Zotero。
2. 对其中的种子论文用 S2 `/citations` + `/references` 滚雪球。
3. 知网用机构「合肥工业大学」+ 主题筛，补国内（尤其本校）相关硕博论文。
4. IEEE/ScienceDirect 校园网补全文与顶会。
5. 全部落 Zotero，按「方法/对象/控制策略」三个标签分组，供写综述用。

# 引用管理

> 目标：检索到的论文**立刻落库**，写综述/申请书时引文与参考文献一键生成，且引用规范符合中文(GB/T 7714)与英文(IEEE/APA)要求。

---

## 1. BibTeX 格式速查

每篇文献一个 `@type{key, 字段}` 条目。常用类型与**必需字段**：

```bibtex
% 期刊论文
@article{key2023,
  author = {Zhang, San and Li, Si},   % 英文姓, 名(可缩写)；中文可用拼音或中文
  title  = {Compliant Grasping of Fragile Objects},
  journal= {IEEE Robotics and Automation Letters},
  year   = {2023},
  volume = {8}, number = {2}, pages = {1000--1012},
  doi    = {10.1109/LRA.2023.xxxxx}
}

% 会议论文
@inproceedings{key2022,
  author = {Wang, Wu},
  title  = {A Soft Gripper for Tomato Picking},
  booktitle = {IEEE/RSJ Int. Conf. on Intelligent Robots and Systems (IROS)},
  year   = {2022}, pages = {1--6},
  doi    = {10.1109/IROS.2022.xxxxx}
}

% 专著
@book{key2020,
  author = {Hogan, N.}, title = {Impedance Control},
  publisher = {MIT Press}, year = {2020}, isbn = {978-0-xxx}
}

% 学位论文
@phdthesis{key2021,
  author = {Chen, Liu}, title = {柔性夹持器设计研究},
  school = {合肥工业大学}, year = {2021}
}
```

**注意**：
- 中文文献用 `@article`/`@phdthesis` 即可，但 `author` 建议用「拼音, 汉字」或纯汉字；若投中文期刊，Reference 部分按 **GB/T 7714** 而非 BibTeX（见第 4 节）。
- 多作者用 `and` 连接：`author = {A, B and C, D}`。
- 始终带 `doi`，这是可追溯性的命根（见 `一手源研究.md`）。

## 2. 从 DOI 获取 BibTeX（已实测可用 ✅）

**这是本包验证过能跑通的命令**（撰写时实测 HTTP 200，返回合法 BibTeX）。原理是 doi.org 的内容协商（Content Negotiation）：用 `Accept: application/x-bibtex` 头向 `https://doi.org/<DOI>` 请求。

```bash
# 把 <DOI> 换成真实 DOI，例如 10.48550/arXiv.1706.03762
curl -sL --ssl-no-revoke -H "Accept: application/x-bibtex" "https://doi.org/10.48550/arXiv.1706.03762"
```

**实测返回示例**（真实输出，非虚构）：

```bibtex
@misc{https://doi.org/10.48550/arxiv.1706.03762,
  doi = {10.48550/ARXIV.1706.03762},
  url = {https://arxiv.org/abs/1706.03762},
  author = {Vaswani, Ashish and Shazeer, Noam and others},
  title = {Attention Is All You Need},
  publisher = {arXiv}, year = {2017}
}
```

> 任何 DOI（期刊/IEEE/ScienceDirect/arXiv 都有）都能这样一键拿 BibTeX，比手动抄字段可靠 10 倍。

**备选**：Crossref 官方转换端点（有时比 doi.org 更稳）：

```bash
curl -sL --ssl-no-revoke "https://api.crossref.org/works/<DOI>/transform/application/x-bibtex"
```

> 提示：中文 DOI（知网论文也有 DOI）同样适用上面两条。

## 3. Zotero 使用要点

Zotero 是免费开源文献管理首选，**与 Word / LaTeX 都能联动**。

- **收集**：
  - 浏览器装 Zotero Connector，打开论文页/PDF 一点即存（自动抓元数据）。
  - 本地 PDF 直接拖进 Zotero，右键「Retrieve Metadata」自动补全。
  - 从 CNKI/IEEE/ScienceDirect 导出 RIS 或 BibTeX 后「文件 → 导入」。
- **与 Word 联动**：
  - 装 Zotero 时勾选 Word 插件；Word 里出现 Zotero 工具条。
  - 「Add/Edit Citation」插入引文，「Add/Edit Bibliography」生成参考文献表。
  - **中文 GB/T 7714 样式**：默认样式库没有，需在 Zotero 样式仓库装「Chinese Std GB/T 7714-2015」样式（官网 Style Repository 搜索下载），再在文档里选该样式。
- **与 LaTeX 联动**：
  - 导出 `.bib` 文件，`\usepackage{biblatex}` + `\addbibresource{ref.bib}`，正文 `\cite{key}`，文末 `\printbibliography`。
  - 中文用 `xelatex` + `biber` 编译（`bibtex` 对中文支持差）。
- **合工大**：可用学校机构邮箱建 Zotero 账号，便于跨设备同步；也可建群组库与小组项目成员共享。

## 4. 引用规范：GB/T 7714 vs IEEE vs APA

| 规范 | 典型用途 | 文内标注 | 参考文献排序 |
|---|---|---|---|
| **GB/T 7714-2015**（中文） | 国内期刊、毕业设计、课程作业 | 顺序编码 `[1]` 或 著者-出版年 `(张三, 2020)` | 按出现顺序 / 拼音 |
| **IEEE**（英文） | 电气/机器人/工科会议期刊 | 方括号序号 `[1]` | 按首次引用顺序 |
| **APA**（英文） | 心理/社科/部分交叉 | 著者-年 `(Author, 2020)` | 按著者字母 |

> 写中文课程作业/申请书 → 用 **GB/T 7714**（顺序编码制最常见）。投英文工科 → **IEEE**。别混用。Zotero 切换样式即一键重排。

## 5. 去重与批量整理

- **去重**：Zotero 左侧「Duplicates」自动比对，合并时保留信息更全的那条（DOI 是合并主键）。
- **批量补全**：对缺字段的条目，用第 2 节的 DOI 命令批量补 `doi`，再「Update」拉全元数据。
- **批量导出**：选中条目 → 右键「导出」→ 选 BibTeX(R)) 生成 `ref.bib`，供 LaTeX 或共享给队友。
- **命名 key 规范**：建议 `第一作者姓+年份+关键字`，如 `zhang2023_compliant`，方便 `\cite` 时回忆。

# 一手源研究

> 融合自 `mattpocock/skills` 的 `/research` 思路，并针对「拒绝模拟数据」偏好改写。
> 核心：**派后台 agent 只查一手源，每条结论附 source，落盘成 md**。本文件管学术严谨性。

---

## 1. 一手源 vs 二手源（判别标准）

| 类别 | 算一手（可直接当证据） | 算二手（只能指引，不能直接引结论） |
|---|---|---|
| 论文 | 原始研究论文、预印本(arXiv) | 综述、科普、他人对论文的解读 |
| 文档 | 官方文档、规格说明书、标准文本 | 教程博客、问答、维基 |
| 代码 | 源码文件（含 **行号**）、官方示例 | 第三方封装、AI 生成的改写 |
| 数据/标准 | 数据集原文件、GB/T 等国家标准 | 别人统计好的图表（除非附原始出处） |
| 模型记忆 | ❌ 不算 | ❌ 绝对不算证据 |

> 铁律：综述里**引一手**，博客/综述只用来「发现」论文，不当作结论来源。

---

## 2. 什么叫「可追溯」（Traceability）

每条结论必须能一路追回去，至少满足其一：

- **DOI**：`10.xxxx/xxxxx`（最稳，能用 `引用管理.md` 转 BibTeX）
- **官方 URL**：论文页、文档页、规格页（带访问日期）
- **文件路径:行号**：本地源码，如 `D:/proj/grasp.py:142`
- **版本号**：软件/数据集版本，如 `v1.3.0`，避免「某版本」这种模糊表述

> 追不到以上任何一项 → 必须标 **「未验证」**，不得写成确定结论。

## 3. 输出模板（结论 + 证据 + 置信度）

落盘 md 时每条断言按此结构：

```markdown
## 结论
柔性抓取中采用阻抗控制可降低接触力峰值，从而减少易损对象（如鸡蛋）损伤。 [置信度: 高]

**证据（一手）**
- Hogan 1985 阻抗控制原始论文，提出等效刚度-阻尼模型。DOI: 10.1115/1.3140xxx
- 来源: https://doi.org/10.1115/1.3140xxx （或本地 PDF 路径）

## 结论
某软体夹爪对番茄损伤率 < 2%。 [置信度: 中]（样本量 n=30，单一文献）

**证据（一手）**
- 文献 X 实验章节，Table 3。DOI: 10.xxxx/xxxxx
```

置信度用法：
- **高**：多源一手一致 / 原始提出者 / 官方文档。
- **中**：单一一手来源，或样本有限。
- **低**：推断或单点观察 → 必须补验。
- 任何无法溯源的 → 标 **「未验证」**，不写置信度。

## 4. 操作流程（派后台 agent 时照做）

1. **明确问题**：把要调研的问题写成 1~3 句断言清单（如「阻抗控制能否降低番茄损伤率？」）。
2. **列需验证断言**：对每个断言，写下「需要什么一手证据才能证明」。
3. **派 agent 只取一手源**：指令里强调「只引用论文原文/官方文档/源码:行号，禁止用模型记忆下结论；无法溯源的标未验证」。
4. **逐条给证据 + 置信度**：agent 返回按第 3 节模板，每条带 DOI/URL/路径。
5. **汇总落盘**：存成 `调研-<主题>.md`，与 Zotero 条目交叉引用。

## 5. 与「联网工具箱」的分工

| 工具 | 管什么 | 什么时候用 |
|---|---|---|
| **本学术研究工具箱 / 一手源研究** | 学术严谨性：一手、可溯源、拒模拟、DOI/BibTeX | 查论文、写综述、做课题调研 |
| **联网工具箱** | 通用网页抓取 / 搜索 / 登录后操作 | 抓普通网页、查通用资料、非学术来源 |

> 学术检索**优先本工具箱 + `论文检索.md`**。联网工具箱适合补「官网、新闻、工具文档」这类非论文来源，但落到学术结论时仍要回本文件做一手校验。

---

## 6. 一句话原则

**没有一手来源的结论，等于没说。** 宁可少写一条带「未验证」的，也不要用二手转述冒充证据——这与你「拒绝模拟数据」的偏好完全一致。

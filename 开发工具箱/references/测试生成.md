# 二级：测试生成

**适用场景**：用户需要生成单元测试、集成测试、E2E测试，或提升测试覆盖率。

---

## 三级执行：测试生成工具

### 测试金字塔

```
        /\
       /E2E\    （少量，关键路径）
      /------\
     /集成测试\  （中等数量，API/模块交互）
    /----------\
   /  单元测试  \  （大量，快速，隔离）
  /--------------\
```

**原则**：
- 单元测试：快速，隔离，覆盖所有边界条件
- 集成测试：验证模块交互，数据库，外部API
- E2E测试：模拟用户行为，覆盖关键业务流程

## 单元测试生成

### Python（pytest + pytest-cov）

```bash
# 安装
pip install pytest pytest-cov pytest-mock

# 生成测试模板（手动）
# 对函数 `add(a, b)` 生成测试：

# tests/test_math.py
import pytest
from my_module import add

def test_add():
    assert add(1, 2) == 3
    assert add(-1, 1) == 0
    assert add(0, 0) == 0

def test_add_float():
    assert add(1.5, 2.5) == 4.0

def test_add_error():
    with pytest.raises(TypeError):
        add("1", 2)
```

## 集成测试生成

### Python（pytest + TestClient）

```python
# tests/test_api.py
import pytest
from fastapi.testclient import TestClient
from my_app import app

client = TestClient(app)

def test_read_main():
    response = client.get("/")
    assert response.status_code == 200
    assert response.json() == {"message": "Hello World"}

def test_create_item():
    response = client.post(
        "/items/",
        json={"name": "Test Item", "price": 10.5},
    )
    assert response.status_code == 201
    assert response.json()["name"] == "Test Item"
```

### 数据库集成测试

```python
# tests/test_database.py
import pytest
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker
from my_app.database import Base, get_db
from my_app.models import User

@pytest.fixture(scope="function")
def db_session():
    engine = create_engine("sqlite:///./test.db")
    Base.metadata.create_all(bind=engine)
    Session = sessionmaker(bind=engine)
    session = Session()
    yield session
    session.close()
    Base.metadata.drop_all(bind=engine)

def test_create_user(db_session):
    user = User(name="Alice", email="alice@example.com")
    db_session.add(user)
    db_session.commit()
    
    assert user.id is not None
    assert user.name == "Alice"
```

## E2E测试生成

### Python（Selenium / Playwright）

```bash
# 安装 Playwright
pip install playwright

```

```python
# tests/test_e2e.py
from playwright.sync_api import sync_playwright

def test_login_flow():
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()
        
        # 访问登录页
        page.goto("https://example.com/login")
        
        # 填写表单
        page.fill("#username", "testuser")
        page.fill("#password", "password123")
        
        # 提交
        page.click("button[type=submit]")
        
        # 验证跳转
        assert page.url == "https://example.com/dashboard"
        assert page.locator(".welcome").text_content() == "Welcome, testuser!"
        
        browser.close()
```

## 测试最佳实践

### 单元测试原则

1. **FAST** — 快速，秒级完成
2. **ISOLATED** — 隔离，不依赖外部状态
3. **DETERMINISTIC** — 确定性，每次结果相同
4. **TIMELY** — 及时，在代码之前或同时编写

### 测试命名规范

```python
# 好的命名
def test_add_returns_sum_of_two_integers():
    pass

def test_divide_raises_value_error_when_denominator_is_zero():
    pass

# 不好的命名
def test1():
    pass

def add_test():
    pass
```

### 使用 Fixtures

```python
# conftest.py
import pytest

@pytest.fixture
def user():
    return {"name": "Alice", "email": "alice@example.com"}

# tests/test_user.py
def test_user_email(user):
    assert user["email"] == "alice@example.com"
```

```yaml

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      - name: Install dependencies
        run: pip install -r requirements.txt
      - name: Run tests
        run: pytest --cov=./ --cov-report=xml
      - name: Upload coverage
        uses: codecov/codecov-action@v3
        with:
          file: ./coverage.xml
```

## 故障排查

| 问题 | 解决方案 |
|------|-----------|
| 测试运行太慢 | 并行运行 `pytest -n 4`（需要 `pytest-xdist`） |
| 测试间状态污染 | 使用 fixtures，每个测试独立 setup/teardown |
| 异步代码测试失败 | 使用 `pytest-asyncio` 或 `anyio` |
| 数据库测试失败 | 使用事务回滚或独立测试数据库 |
| E2E测试不稳定 | 添加显式等待 `page.wait_for_selector()` |

---

## 注意事项

1. **不要为了覆盖率而写无意义的测试** — 测试质量 > 数量
2. **测试应该是确定性的** — 避免随机值、时间依赖
3. **Mock外部依赖** — 网络、数据库、文件系统
4. **定期运行测试** — CI/CD自动运行，本地pre-commit运行

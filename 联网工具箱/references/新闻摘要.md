# 二级：新闻摘要

**适用场景**：获取最新新闻、每日简报、特定主题新闻汇总

> **本层零依赖可用。** RSS 就是 XML，用本工具箱自带的 `scripts/rss.mjs`（原生 fetch 解析，不依赖 feedparser）即可。

---

## 工具对比

| 工具 | 速度 | 依赖 | 费用 | 推荐场景 |
|---|---|---|---|---|
| **`scripts/rss.mjs`** | 快 | **无** | 免费 | 每日简报、固定领域跟踪（**首选**） |
| WebSearch | 快 | 无 | 无 | 快速查询某个具体事件的最新动态 |
| NewsAPI | 中 | 需 `NEWSAPI_KEY` | 免费额度+按量 | 主题新闻搜索（**本机未配 key**） |

---

## 首选：`scripts/rss.mjs`（零依赖）

```bash
# 综合新闻：中国新闻网 + 界面新闻
node scripts/rss.mjs --preset news

# 科技：36氪 + IT之家 + 少数派
node scripts/rss.mjs --preset tech

# AI：量子位 + 爱范儿
node scripts/rss.mjs --preset ai

# 开发者向：Solidot + 小众软件
node scripts/rss.mjs --preset dev

# 全部内置源，每个源只取 5 条
node scripts/rss.mjs --preset all --limit 5

# 只看最近 1 天 / 最近 6 小时
node scripts/rss.mjs --preset tech --since 1d
node scripts/rss.mjs --preset news --since 6h

# 自定义源（可重复 --url）
node scripts/rss.mjs --url https://example.com/feed.xml --url https://other.com/rss

# 机器可读（Agent 用来二次处理）
node scripts/rss.mjs --preset all --json

# 看内置源清单与已知失效源
node scripts/rss.mjs --list-presets
```

输出是 Markdown 列表（时间 + 标题 + 链接），可直接接着做总结。

### ⚠️ 已知失效（都是"看起来能抓、实际没用"的假活源）

| 源 | 现象 |
|---|---|
| **新华网时政** | HTTP 200 且 **300 条**，但**条目无 pubDate 且内容是 2022 年的** —— 冻结源 |
| **人民网时政** | HTTP 200 且 **100 条**，最新条目停在 **2025-06-05** —— 冻结源 |
| **知乎 `/rss`** | HTTP 200 但 **body 为 0 字节** |
| 机器之心 / 澎湃新闻 | 200 但 **0 条目** |
| BBC / rsshub.app | 直连不可达（`000`） |

### 教训：判断源是否可用，要看"最新条目日期"，不是条数

上面两个"冻结源"都返回 200 且条数很多，只看"抓到了多少条"会以为它们正常，
结果引用到的是 2022 年的旧闻。**`rss.mjs` 已内置新鲜度检查**：
最新条目超过 30 天会提示「疑似冻结源」，无日期会提示「谨慎使用」。

> 这和「HTTP 200 不等于有内容」是同一类错误——**状态码和条数都不是可用性证明**。

## 使用建议

1. **每日简报** → `node scripts/rss.mjs --preset all --limit 5`（可挂定时任务）
2. **跟踪某领域** → 用上面对应的 `--preset`；找该领域专属 RSS 时用 `--url` 传入
3. **追一个具体事件** → WebSearch（RSS 适合按领域跟踪，不适合追单一事件）
4. **需要引用** → RSS 只给标题和链接，**必须打开原文核对**再引用

## 故障排查

| 问题 | 解决方案 |
|---|---|
| 源返回 200 但没条目 | 假活源（知乎 / 机器之心 / 澎湃）。用 `--json` 看 `error` 与 `count` |
| 提示「疑似冻结源」 | 该源内容不更新了（新华网 / 人民网）。换源，别引用旧闻 |
| 提示「无可用日期」 | 该源缺 pubDate，无法判断新鲜度。谨慎引用，或换源 |
| 抓取超时 | 脚本 25s 超时；该源可能需代理，换国内源 |
| 条目时间显示"时间未知" | 部分源 pubDate 格式不规范；该条不会被 `--since` 过滤掉 |
| 想要更多源 | `--list-presets` 看内置；其余自行用 `--url` 加。**加之前先看最新条目日期** |
| 想跑定时简报 | 用 `automations` 建每日任务，prompt 里写 `node scripts/rss.mjs --preset all` |

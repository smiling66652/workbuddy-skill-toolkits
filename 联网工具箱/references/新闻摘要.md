# 二级：新闻摘要

**适用场景**：用户需要获取最新新闻、每日简报、特定主题新闻汇总

---

## 工具对比

| 工具 | 速度 | 来源 | 费用 | 推荐场景 |
|------|------|------|------|------------|
| **RSS聚合** | 快 | 可信RSS源 | 免费 | 每日简报 |
| **NewsAPI** | 中 | 全球新闻源 | 免费额度+按量 | 主题新闻搜索 |
| **WebSearch** | 快 | 搜索引擎 | 模型token费 | 快速查询最新动态 |

## 三级执行：RSS聚合（推荐）

**触发词**：今天有什么新闻、最新动态、每日简报、科技新闻

```python
# 安装依赖
pip install feedparser

# 获取RSS新闻
python -c "
import feedparser
import datetime

feeds = [
    'http://rss.cnn.com/rss/edition.rss',
    'https://feeds.bbci.co.uk/news/rss.xml',
    'https://www.reddit.com/r/worldnews/.rss',
]

for feed_url in feeds:
    feed = feedparser.parse(feed_url)
    print(f\"=== {feed.feed.title} ===\")
    for entry in feed.entries[:5]:
        print(f\"- {entry.title}\")
        print(f\"  {entry.link}\")
        if hasattr(entry, 'published'):
            print(f\"  {entry.published}\")
        print()
"
```

## 三级执行：NewsAPI（主题新闻搜索）

**触发词**：关于XX的最新新闻、XX事件报道

**前置条件**：需要 `NEWSAPI_KEY`

```bash
# 安装
pip install newsapi-python

# 搜索新闻
python -c "
from newsapi import NewsApiClient
newsapi = NewsApiClient(api_key='YOUR_KEY')
articles = newsapi.get_everything(q='AI', language='zh', sort_by='publishedAt', page=1)
for article in articles['articles'][:5]:
    print(f\"{article['title']} - {article['source']['name']}\")
    print(f\"  {article['url']}\")
    print()
"
```

**免费额度**：每天100次请求

## 使用建议

1. **每日简报** → RSS聚合（定时任务）
2. **主题新闻搜索** → NewsAPI（需API key）

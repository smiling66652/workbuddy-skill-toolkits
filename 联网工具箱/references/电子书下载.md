# 二级：电子书 / 教材下载

**适用场景**：要下载某本教材、专著、绝版书的 PDF；搜 ISBN；找教材配套资源

> 本页是**执行层**：把「书名/ISBN → 拿到 PDF」跑通，含本工具箱自带的 5 个自动化脚本。
> 方法论（多源顺序、代理坑、降级路径）已并入本页，**无需再加载其他技能包**。

---

## 流程总览

```
① 查准元数据（ISBN / 版次）
      ↓
② 配好代理（命令行不会自动走代理）
      ↓
③ 按 4 个梯队找源，命中即停
      ↓
④ 用本工具箱的 5 个脚本自动下载
      ↓
⑤ 拿不到 → 走降级路径（MOOC → 正版 → 替代教材 → 文献传递）
```

## ① 元数据先行（必做，别跳过）

用错 ISBN 会白跑一整轮。**一本书的不同版次 ISBN 完全不同，两个都要试。**

```
WebSearch: "<书名> <作者> 出版社 ISBN 版次"
```

- 中文书可用 `book.cppinfo.cn`（国家出版发行信息公共服务平台）核对 ISBN 与目录
- 顺手记下：版次、出版社、页数 —— 后面判断下载到的文件对不对全靠这些

---

## ② 代理配置（命令行出国的正确姿势）

**命令行工具不会自动走系统代理**，必须显式指定。本机 v2rayN 的 socks 入站端口是 `10808`。

```bash
# ✅ 正确：--socks5-hostname 让远程解析 DNS，最稳
curl -sL -m 30 --socks5-hostname 127.0.0.1:10808 "<URL>" \
  -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"

# ❌ 避免：-x socks5:// 形式对部分域名会失败
```

### 三个高频坑

| 坑 | 现象 | 解法 |
|---|---|---|
| **沙箱阻断 loopback** | 连 `127.0.0.1` 失败 / 浏览器网络被阻断 | 加 `dangerouslyDisableSandbox: true` 沙箱外执行 |
| **Python 自写 socks5** | `SSLEOFError` / `WinError 10053` | 别用 Python，改用 curl 或浏览器 |
| **TUN 模式误伤国内站** | 夸克/百度网盘报"网络异常 请稍后重试" | 下载国内网盘前临时关 TUN 或切回系统代理 |

### 排查顺序

1. 浏览器能翻墙但命令行不行 → 端口不对，`netstat -ano | grep LISTENING` 找真实端口
2. 全站返回 `000` → 节点挂了，换节点
3. 只有特定域名失败 → 节点屏蔽该域，换镜像

## ③ 多源检索顺序（2026-09 实测状态）

按此顺序跑，**命中即停**。每个源用 ISBN 和书名各搜一次。

### 第 1 梯队：元搜索引擎（覆盖最广，先试这个）

**Anna's Archive** —— 覆盖 Z-Lib / LibGen / DuXiu / IA / Sci-Hub / Hathi

```
https://annas-archive.gd/search?q=<ISBN>
```

- ⚠️ **主站 `.org` 常被节点屏蔽**；可用镜像：`.gd` `.gl` `.pk` `.se` `.in`
- ⚠️ 有 **DDoS-Guard JS 挑战，headless 过不去** → 首选 [CDP 直连](CDP浏览器直连.md)日常 Edge（真实浏览器 + 自带登录态），或去掉 `--headless` 用可见窗口
- 结果页左侧分面（Filetype / Source / Language）能直接看有没有 `zh` / `pdf` / `libgen` 源

### 第 2 梯队：直连检索

```
LibGen        https://libgen.li/index.php?req=<ISBN>       ← 注意是 index.php 不是 search.php
Z-Library     https://z-lib.id/s/<ISBN>                     ← 2026-09 真实域名，其他多为域名出售页
              https://z-lib.id/search?q=<书名>
Internet Archive（用 API，别爬页面）
              https://archive.org/advancedsearch.php?q=<ISBN>&fl[]=identifier,title,creator,isbn,date&output=json
              https://archive.org/metadata/<identifier>      ← 看元数据与文件列表
              https://archive.org/download/<identifier>/<identifier>.pdf
```

### 第 3 梯队：目录型（判断"到底存不存在"）

| 源 | 端点 | 怎么读 |
|---|---|---|
| OpenLibrary | `https://openlibrary.org/search.json?q=<ISBN>` | 看 `numFound` |
| HathiTrust | `https://catalog.hathitrust.org/api/volumes/brief/oclc/isbn/<ISBN>.json` | `records:{}` 即无 |
| Google Books | `https://www.googleapis.com/books/v1/volumes?q=isbn:<ISBN>` | 常有 429 限速 |
| GitHub | `https://github.com/search?q=<ISBN>&type=repositories` | 匿名可搜仓库 |
| grep.app | `https://grep.app/api/search?q=<ISBN>` | 代码搜索 |

### 第 4 梯队：中文专用

| 源 | 状态 |
|---|---|
| **鸠摩搜书** jiumo.com / jiumo.net | ❌ **2026-09 全部镜像已挂，省时间别试** |
| 学兔兔 bzfxw.com | 有书，下载需登录 |
| 全国图书馆参考咨询联盟 ucdrs.superlib.net | 需登录，走「文献传递」按页收邮件 |
| **出版社官网** | 常有配套课件/数字资源，务必查（例：press.hfut.edu.cn） |
| **读秀 / 超星** | 走学校 CARSI，馆藏纸本必中 |

## ④ 本工具箱的自动化脚本

脚本依赖工具箱自带的 **playwright（1.63.0）+ 系统 Edge**，无需额外安装浏览器。
默认下载目录 `D:/桌面/电子书/_downloads`，默认浏览器 `edge`，使用**独立 profile**（不占用你的主浏览器）。

统一调用姿势（用托管 Node）：

```bash
NODE="C:/Users/Matebook/.workbuddy/binaries/node/versions/22.22.2-2/node.exe"
DIR="C:/Users/Matebook/.workbuddy/skills/联网工具箱/scripts"
```

| 脚本 | 用途 | 状态 |
|---|---|---|
| `archiveorg-find.mjs` | **IA API 版**，advancedsearch + metadata 接口 → 直链下载 | ✅ 推荐（比 UI 版快且稳） |
| `archiveorg-search-download.mjs` | IA 网页搜索拿 identifier → metadata 接口筛 PDF → 下载 | ✅ 推荐（规避了 ISBN 字段索引坑） |
| `archiveorg-download.mjs` | IA **UI 搜索**版 | ⚠️ 较慢，建议优先用上面两个 |
| `annas-archive-download.mjs` | Anna's Archive 按 ISBN 走 Slow download | ⚠️ 需代理；遇 DDoS-Guard 要可见窗口 |
| `jiumo-find.mjs` | 鸠摩搜书兜底 | ❌ **已失效**（该站 2026-09 全镜像已挂）；仅留作历史参考 |

### Internet Archive（首选，不受代理黑名单影响）

archive.org 是合法公益数字图书馆，**通常不在 VPN 服务商的盗版站屏蔽名单内**，因此比 Anna's / Z-Library 更适合受限代理环境。

```bash
"$NODE" "$DIR/archiveorg-find.mjs" \
  --isbn 9787040422979 \
  --name "热工基础-第3版-张学学" \
  --download-dir "D:/桌面/电子书/_downloads"
```

### Anna's Archive（覆盖最广，但有 JS 挑战）

```bash
"$NODE" "$DIR/annas-archive-download.mjs" \
  --isbn 9787565066580 \
  --name "工程材料及成形技术基础-第2版-郑红梅" \
  --download-dir "D:/桌面/电子书/_downloads" \
  --proxy 127.0.0.1:10808      # 去掉 --headless 让窗口可见，便于过 JS 挑战
```

**通用参数**：`--browser edge|chrome`（默认 edge）、`--profile <档案名>`、`--headless`、`--proxy`、`--timeout <ms>`

> 若脚本卡在挑战页：改用 [CDP 直连](CDP浏览器直连.md) 打开同一 URL（真实浏览器环境天然过挑战），
> 拿到 PDF 直链后再用 `curl --socks5-hostname` 下载。

## ⑤ 降级路径（原书拿不到时）

按推荐度排序：

1. **MOOC 配套**（最优，合法且比纸本立体）—— 中国大学MOOC / 学银在线 / 智慧树，搜作者名或书名；国家级一流课程常有全套课件 + 视频 + 虚拟仿真
2. **买正版** —— 当当 / 京东 / 文轩，教材通常 40–50 元
3. **同类替代教材** —— 用 IA / LibGen 搜**同主题不同作者**的教材，章节结构常高度相似
4. **馆际文献传递** —— ucdrs，按页码分次发邮箱（一次约 50 页）

**判据**：如果 **Anna's Archive（覆盖全球最大 6 个库）都是 0 结果**，基本可判定**全网无免费电子版**，直接转降级路径，别再耗时间。

## 与 `ebook-fetch` 技能包的关系

`ebook-fetch` 是同一件事的**另一个入口**（只有 SKILL.md，无脚本）。本页已吸收其全部方法论。

**现状：两者功能重叠。** 建议二选一：
- 若你只想调一个技能 → 用本工具箱（本页已自足），可考虑停用 `ebook-fetch`
- 若你想保留独立的"找书"入口 → 保留 `ebook-fetch` 作为方法论，本页当执行层

另外注意：`ebook-fetch` 引用的 `D:\桌面\电子书\tools\aaget.py` / `proxyprobe.py` / `socksget.py` 是**外部依赖**，不在技能包内；本工具箱不依赖它们。

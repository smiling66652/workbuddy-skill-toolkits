# 二级：反爬对抗

**适用场景**：静态层与常规浏览器都拿到 403 / 挑战页 / "Verify you are human" / 空内容时

> **先做这一件事**：确认你遇到的**真的是反爬**。
> 内容为空也可能是「页面需要 JS 渲染」「URL 缺必要参数」「内容在 Shadow DOM / iframe 里」「懒加载未触发」。
> 用 CDP `/eval` 看一眼 DOM 实际内容再下结论。误判成反爬会让你绕一大圈。

---

## 反爬在你身上查什么（Cloudflare 五层）

Cloudflare 挡在约 **20%** 的网站前面。它按信任分决定放行 / 挑战 / 拦截，且**分数据实时调整**——首屏过了不代表后面不会被拦。

| 层 | 查什么 | 典型表现 |
|---|---|---|
| **TLS 指纹** | JA3 / JA4 握手签名。Python `requests`、Go、Node axios 各不相同，和真浏览器差得远 | 请求还没到服务器就被拒 |
| **IP 信誉** | 数据中心 IP 默认被标记；住宅 / 移动 IP 宽松得多 | 换网络就好，换 UA 没用 |
| **JS 挑战** | `navigator.webdriver`、canvas 渲染、WebGL、插件数组、字体列表 | 5 秒盾 / 无限循环验证 |
| **行为分析** | 请求时序、鼠标轨迹、滚动模式；同 IP 高频同间隔 = 明显是脚本 | 前几页正常，之后突然全拦 |
| **Turnstile** | 人机验证组件 | 显式"验证您是人类" |

**两个关键认知**：

1. **`navigator.webdriver` 只是最基础那一层**。Cloudflare 还有几十项检查，别以为把它改成 `undefined` 就完事。
2. **UA 单打独斗 2022 年起就失效了**。UA 声称 Windows 而 canvas 指纹显示 macOS，反而是**明确的失配信号**。一致性比伪装更重要。

## 分层对抗路线（成本从低到高，严格按顺序试）

### 第 1 层：CDP 直连真实浏览器 ← 首选，且免费

**先试这个，不要先试下面的**。

原理：连的是**未经 `--enable-automation` 启动的日常浏览器**，`navigator.webdriver` 天然为 `false`，Cookie、指纹、扩展、历史全是真的。对 Cloudflare 来说这就是个真实用户。

```bash
node "C:/Users/Matebook/.workbuddy/skills/联网工具箱/scripts/check-deps.mjs"
curl -s -X POST --data-raw 'https://目标站' http://localhost:3456/new
curl -s -X POST "http://localhost:3456/eval?target=ID" -d 'document.body.innerText'
```

**为什么它通过率高于任何自动化实例**：不需要伪装——它本来就是真浏览器。所有 stealth 插件都在"改造一个假浏览器让它看起来真"，而这条路用的是真的。

### 第 2 层：agent-browser 接默认上下文

CDP Proxy 不方便（比如要交互、要视觉标注）时：

```bash
agent-browser --cdp 9222 snapshot        # 复用真实 cookie jar
agent-browser --auto-connect snapshot    # 自动发现已开的 Chrome/Edge
```

⚠️ 必须带 `--cdp` 或 `--profile`。**standalone 模式是隔离上下文**，反检测能力并不比 Playwright 强。

> ⚠️ **2026-09-12 实测：`agent-browser` CLI 当前不在本机**（仅剩 `~/.agent-browser/` 缓存）。
> 走这层前先 `npm install -g agent-browser && agent-browser install`；
> 或用 `scripts/pw.mjs`（本机已就绪）替代，用法见 [playwright高级用法](playwright高级用法.md)。

### 第 3 层：nodriver（免 WebDriver，免费）

Python 库，由 undetected-chromedriver 作者开发。不走 WebDriver 协议、直接与 Chrome 通信，**不留下 WebDriver 痕迹**。

社区实测（`nowsecure.nl` Cloudflare Turnstile 测试站）：

| 方案 | 结果 | 通过耗时 |
|---|---|---|
| 原生 Playwright / Playwright MCP | ❌ 失败 | 无限卡挑战页 |
| playwright-extra + stealth | ✅ 通过 | 约几秒 |
| **nodriver** | ✅ 通过 | **约 1 秒** |

```python
import nodriver as uc
browser = await uc.start()
page = await browser.get('https://目标站')
```

**⚠️ 硬约束：nodriver 不支持 Python 3.14**。本机必须用 **3.13** —— 也就是托管 venv：

```bash
C:/Users/Matebook/.workbuddy/binaries/python/envs/default/Scripts/python.exe -m pip install nodriver
```

### 第 4 层：curl_cffi（TLS 指纹伪装，最轻）

**不是所有站都要浏览器**。只做 TLS + 头部校验的端点，在网络层就够：

```python
from curl_cffi import requests
r = requests.get(url, impersonate="chrome")   # 复刻浏览器的 JA3/JA4 签名
```

- ✅ 极省资源（无浏览器），适合"先快速试一次"
- ❌ 对 JS 挑战无效
- ⚠️ **UA 必须和 impersonate 的浏览器一致**，Chrome 的 JA3 配 Firefox 的 UA = 立刻暴露
- ⚠️ 原始 `curl-impersonate` 的 TLS 模式已被 Cloudflare 适应，效果不如从前

### 第 5 层：camoufox（换内核）

有些 Cloudflare 部署针对 Chrome 做了**专属检测规则**。camoufox 是改造过的 Firefox，提供真实 Firefox 指纹，绕开 Chrome 专属规则。

但本机日常浏览器是 Edge/Chrome，换内核意味着**放弃登录态**——只在"不需要登录 + Chrome 路线全废"时用。

### 第 6 层：付费方案（最后手段）

| 方案 | 成本量级 | 说明 |
|---|---|---|
| 住宅代理 | $8–15 / GB | 解决 IP 信誉层。一个商品页含资源 2–5MB，规模化很贵 |
| 浏览器农场 | $50–200 / 月 | 真实浏览器 + 真 TLS 栈 |
| 托管绕过 API | 按请求 | 把代理/指纹/验证码全交给第三方 |

**判断线**：每月 <1 万页 → 前 5 层 + 住宅代理够用；> 1 万页 → 托管 API 的时间成本更划算。

## 错误码 / 现象诊断

| 现象 | 含义 | 该做什么 |
|---|---|---|
| Cloudflare **1020** | 访问被规则拒绝 | **IP 问题** → 换住宅代理，不是换浏览器 |
| Cloudflare **1010** | 浏览器指纹被识别 | **指纹问题** → 上 stealth 浏览器 / nodriver |
| **403** + Cloudflare 页 | 综合风控 | 先试 CDP 直连（第 1 层） |
| **503** + "Just a moment" | JS 挑战未通过 | 需要真浏览器渲染，curl 类方案无效 |
| 前几页正常，之后全拦 | **行为分析**触发 | 加随机延迟、降低频率、别固定间隔 |
| `navigator.webdriver` = true | 自动化痕迹 | 用 CDP 直连真实浏览器（天然 false） |
| JSON 里字段缺失 / 空数组 | 可能不是反爬 | 检查 JS 渲染、URL 参数、懒加载 |

**验证你自己的环境**：`https://nowsecure.nl` 是专门用来测反检测的 Cloudflare Turnstile 站点。上任何方案前先在这测一次。

## 行为层对抗（技术之外）

前面的层都过了仍被拦，问题通常在这：

- **别固定间隔**。同 IP、同节奏的请求是最明显的脚本特征
- **别并发驱动同一标签页**。多个 Agent 同时操作一个 tab 会互相干扰导航、页面状态、网络拦截，也更容易被识别
- **降低 `/new` 密度**。短时间密集开页会触发风控
- **会话预热**。先访问首页 → 停留 → 再进目标页，比直接深链自然

---

## ⚠️ 安全注意（本机相关）

- **调试端口只能监听回环**。不要让 CDP 端口对局域网 / 公网可见——那等于把你的登录态敞开
- **不要拿日常 profile 开对外可见的调试端口**。本技能的 Proxy 跑在 `127.0.0.1:3456`，符合要求
- **不要为了过验证而长期挂住宅代理**跑日常账号，风控会关联到你的真实账号
- 部分站点对自动化检测严格，**存在账号封禁风险**。这是接受操作前必须知道的前提

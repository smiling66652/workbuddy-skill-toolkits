# 二级：智能搜索

**适用场景**：用户需要搜索信息、查资料、找最新进展

## 三级执行

```bash
# 方法1：使用 WebSearch 工具（优先）
# 直接调用 WebSearch，支持中英文引擎自动选择

# 方法2：使用 WebFetch 抓取搜索结果页
# 高级语法：
# site:github.com react      # 站内搜索
# filetype:pdf 报告        # 指定文件类型
# "机器学习"                # 精确匹配
# -time:h  AI新闻          # 过去1小时
```

## 工具对比

| 工具 | 速度 | 精度 | 适用场景 |
|------|------|------|------------|
| WebSearch | 快 | 高 | 通用搜索 |
| WebFetch | 中 | 中 | 抓取搜索结果页 |
| cli-hub search | 快 | 高 | 专业CLI工具搜索 |

## 使用 cli-anything-hub 搜索工具

```bash
# 安装 cli-hub
pip install cli-anything-hub

# 搜索图片处理工具
cli-hub search image

# 搜索3D建模工具
cli-hub search "3d modeling"

# 列出所有可用工具
cli-hub list

# 安装指定工具
cli-hub install gimp
```

## 故障排查

| 问题 | 解决方案 |
|------|-----------|
| WebSearch 无结果 | 更换搜索关键词，或改用 WebFetch |
| cli-hub 未找到 | 运行 `pip install cli-anything-hub` |
| 搜索结果不准确 | 使用高级语法缩小范围 |

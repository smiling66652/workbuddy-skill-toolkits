# 二级：内容总结

**适用场景**：用户需要总结文章、视频、音频、PDF

## 三级执行

**支持类型**：网页URL、PDF、Word、PPT、Excel、图片（OCR）、音频（转写）、YouTube、EPUB

```bash
# 方法1：使用 summarize CLI（如果已安装）
summarize https://example.com/article

# 方法2：使用 WebFetch 抓取后让 LLM 总结

# 方法3：使用 MiniMax CLI 总结（如果已安装）
mmx text chat --message "总结这篇文章：[文章内容]"
```

## Jina 预处理（可选）

在 WebFetch 前加 `r.jina.ai/` 前缀，将网页转为 Markdown，大幅节省 tokens。

## 使用 summarize CLI

```bash
# 安装 summarize
pip install summarize

# 总结网页
summarize https://example.com/article

# 总结本地文件
summarize article.pdf

# 总结YouTube视频
summarize https://youtube.com/watch?v=xxx
```

## 使用 MiniMax CLI 总结

```bash
# 安装 MiniMax CLI
npm install -g mmx-cli

# 总结文本
mmx text chat --message "总结这篇文章：[文章内容]"
```

## 故障排查

| 问题 | 解决方案 |
|------|-----------|
| summarize 未找到 | 运行 `pip install summarize` |
| MiniMax CLI 未找到 | 运行 `npm install -g mmx-cli` |
| 总结结果不准确 | 尝试更换总结方法，或提供更明确的指令 |
| 文件太大 | 先提取需要的章节再处理 |

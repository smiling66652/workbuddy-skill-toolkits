# 二级：浏览器自动化

**适用场景**：用户需要操作网页、点击、填表、截图、登录后操作

## 工具对比

| 工具 | 速度 | 反检测能力 | 适用场景 |
|------|------|--------------|------------|
| **Playwright CLI（推荐）** | 非常高 | 中等 | 本地浏览器，支持登录态 |
| **Agent Browser** | 中 | 高（AI驱动） | 视觉理解，自然语言操作 |
| **Human Browser** | 高 | **极高（97%绕过率）** | 绕过 Cloudflare 等反爬 |
| Selenium | 中等偏慢 | 低（需额外工具） | 跨浏览器测试 |
| Puppeteer | 高 | 中（需Stealth插件） | Chrome/Chromium自动化 |

---

## 三级：Playwright CLI（推荐）

**触发词**：打开网页、点击、填表、截图、登录后操作

### 前置检查（首次使用时运行）

```bash
node "${CLAUDE_SKILL_DIR}/scripts/check-deps.js"
```

### 常用操作

```bash
# 打开浏览器
playwright-cli open

# 打开并导航
playwright-cli open https://example.com/

# 截图
playwright-cli screenshot

# 获取页面快照（获取元素引用）
playwright-cli snapshot

# 读取快照输出（保存到 .playwright-cli/ 目录）
cat .playwright-cli/page-*.yml | tail -200

# 点击元素
playwright-cli click e3

# 输入文本
playwright-cli type "search query"

# 关闭浏览器
playwright-cli close
```

### 使用特定浏览器

```bash
playwright-cli open --browser=chrome
playwright-cli open --browser=firefox
playwright-cli open --browser=webkit
```

### 持久化会话

```bash
# 创建持久化会话
playwright-cli -s=mysession open example.com --persistent
playwright-cli -s=mysession click e6
playwright-cli -s=mysession close
```

### 注意事项

- 不在用户已有 tab 中操作，全部在自建后台 tab 中进行
- 完成任务后关闭自己创建的 tab，保留用户 tab 不变
- 部分站点有反爬限制，存在账号封禁风险

## 三级：Agent Browser（AI驱动）

**触发词**：用AI操作浏览器、视觉理解、自然语言操作浏览器

### 安装

```bash
npx @agent-browser/cli install
```

### 使用示例

```bash
# 打开网页
npx agent-browser open https://example.com

# 用自然语言操作
npx agent-browser act "click the Login button"

# 获取页面快照
npx agent-browser snapshot

# 截图
npx agent-browser screenshot

# 关闭
npx agent-browser close
```

### 特点

- 视觉理解能力，能"看"到页面内容
- 自然语言指令，无需指定元素ID
- 适合复杂页面交互

## 三级：Human Browser（绕过反爬）

**触发词**：绕过 Cloudflare、绕过反爬、住宅IP、iPhone指纹

### 安装

```bash
clawhub install human-browser
# 或
npm install -g human-browser-cli
```

### 使用示例

```bash
# 打开网页（自动使用住宅IP+iPhone指纹）
human-browser open https://example.com

# 用自然语言操作
human-browser act "click the Login button"

# 获取页面内容
human-browser snapshot

# 截图
human-browser screenshot
```

### 费用

- 前 $1 免费
- 后续按量付费（$0.05/分钟 + $4/GB流量，无订阅费）

### 适用场景

- 绕过 Cloudflare、DataDome、LinkedIn 等反爬系统
- 需要住宅IP的场景
- 需要iPhone设备指纹的场景

## 故障排查

| 问题 | 解决方案 |
|------|-----------|
| Playwright CLI 未找到 | 运行 `npm install -g @playwright/mcp@latest` |
| Agent Browser 未找到 | 运行 `npx @agent-browser/cli install` |
| Human Browser 未找到 | 运行 `clawhub install human-browser` |
| 截图失败 | 检查浏览器是否已打开，使用 `playwright-cli open` |
| Cloudflare 拦截 | 使用 Human Browser（住宅IP+iPhone指纹） |

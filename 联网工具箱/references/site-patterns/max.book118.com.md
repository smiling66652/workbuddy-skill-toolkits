# 原创力文档（max.book118.com）· 站点经验

> 首次发现：2026-06-26 ｜ 最近复核：2026-09-12
> 状态：来自 kill-doc 文档的转述，尚未在本机完整走通全流程，当作「可能有效的提示」而非保证

## 平台特征

- 需要登录才能下载完整文档
- 预览页数有限（通常只有前几页免费）
- 下载原始文件需要 VIP 会员
- 下载流程中需要保持浏览器全屏，缩小窗口会导致截取/下载失败
- 中文文档站，属 kill-doc 支持的 30+ 站点之一

## 有效模式

1. **首选 kill-doc Tampermonkey 脚本**（v7.7+ 实测可用）：支持自动预览、下载图片、下载 PDF、获取文本
2. **保持浏览器全屏**：下载时不要缩小窗口，这是全流程里最容易踩的操作细节
3. **大文件支持**：可从指定页码开始预览，绕开前几页的免费额度
4. 分层策略与 kill-doc 安装步骤见 [付费文档下载](../付费文档下载.md)

## 已知陷阱

- 免费预览页数有限，无法预览全部内容
- 直接通过 `requests` / Playwright 下载原始文件会被 VIP 墙拦住——**不要在这条路上耗时**
- 手动构造下载 URL 通常缺会话参数，表现为「文件不存在」或 403，应改走页面内交互

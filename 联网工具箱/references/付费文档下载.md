# 付费文档下载策略

**适用场景**：用户需要下载百度文库、原创力(Book118)、夸克文档、道客巴巴、豆丁网等中文文档网站的受限内容

## 痛点分析

大多数中文文档网站（如百度文库、原创力、CSDN、夸克文档、道客巴巴等）有以下限制：
- 需要登录才能查看/下载完整内容
- 需要VIP/付费会员才能下载
- 有反爬虫机制（安全验证、Cloudflare等）
- 预览页数受限（只能看前几页）

## 遇到登录墙怎么办？（核心策略）

**核心原则**：不放弃、中断让用户手动介入、然后自动恢复。

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│   kill-doc 支持？                                            │
│       │                                                      │
│       ├── ✅ 是 → 直接用 kill-doc 下载（无需登录）             │
│       │          三步：自动预览 → 停止 → 下载PDF              │
│       │                                                      │
│       └── ❌ 否 → 网站需要登录？                              │
│                   │                                          │
│                   ├── 是 → 启动有头浏览器                      │
│                   │        通知用户手动登录                    │
│                   │        用户确认"好了"                      │
│                   │        恢复自动化 → 截图/下载              │
│                   │                                          │
│                   └── 是Cloudflare反爬？                      │
│                         → Human Browser（97%绕过率）          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 手动登录介入流程（详细）

1. **检测**：识别登录弹窗 / URL 跳转到登录页 / 付费遮挡层
2. **打开有头浏览器**：用 Playwright 持久化会话（headless=False），开一个用户可见的窗口
3. **通知用户**："网站需要登录，请在打开的浏览器中手动完成登录"
4. **等待**：每3秒轮询检查登录状态（URL恢复 / DOM出现内容 / 弹窗消失）超时120秒
5. **用户确认**：登录完成后用户说"好了"/"继续"，或自动检测到登录成功
6. **恢复自动化**：在当前会话中继续截图/下载，完成后关闭窗口

### 技术原理

kill-doc 并非破解或逆向文档网站，而是通过以下方式工作：
1. **页面渲染分析**：监控浏览器对文档页面的渲染过程
2. **自动预览**：模拟滚动页面，让所有文档内容进入可视区域
3. **内容截取**：从Canvas、图片等元素中提取已渲染的文档内容
4. **智能重组**：将截取的内容合并为PDF/ZIP/TXT文件

> ⚠️ 脚本仅将画布或图片在浏览器渲染时进行下载拼接PDF，**无法下载原始文件，并非破解**

### 使用流程

1. 打开目标文档页面
2. 按顺序点击右侧功能按钮：
   - **(1) 自动预览** → 让脚本滚动页面，加载所有内容
   - **(2) 停止预览** → 等待滚动完成
   - **(3) 下载PDF** → 导出为PDF文件
   - 或 **(3) 下载图片** → 导出为图片ZIP包
   - 或 **(4) 获取文本** → 提取纯文本内容

### 各平台使用技巧

#### 原创力文档（Book118）
- PPT下载时需要保持浏览器全屏**不要缩小浏览器窗口**
- 大文件支持从指定页码开始预览
- 确保页面完全加载后再执行下载操作

#### 百度文库
- **可编辑PDF**：点击编辑文档 → 自动预览 → 打印PDF
- **文本内容**：自动预览后点击"获取全文"
- **遇到空白页**：使用打印PDF功能（Ctrl+P另存为PDF）
- Word/PDF文档自动预览后不能复制文本，需先复制再预览

#### 夸克文库
- 支持PDF和Word格式
- 暂不支持PPT格式
- 自动预览可能不完全，可手动滚动后再下载

#### 道客巴巴
- 获取文本功能需要预览全文，否则数据不完整
- 支持高质量PDF导出

#### 豆丁网
- 默认只展示部分内容，需登录获取更多
- 大文件（上百页）分页下载策略：
  1. 原始地址后加 `?toImg=1`
  2. 先预览100页 → 停止 → 下载
  3. 刷新页面 → 修改页码到100页 → 继续

## 自动化下载工作流（Playwright/AI Browser）

当需要自动化下载文档时，遵循以下工作流：

### 场景1：文档可免费预览
1. 使用 Playwright CLI 或 Agent Browser 打开文档页面
2. 截图保存页面内容
3. 滚动页面继续截图
4. 将所有截图保存到目标文件夹

### 场景2：文档需登录查看（登录墙中断-恢复）

**这是最常见的场景，按以下流程处理**：

1. **自动检测**：导航到文档页面后，检测是否触发登录墙
   - 识别条件：URL跳转到 `/login` / 登录弹窗 / 付费遮挡 / "请登录后查看"
2. **启动有头浏览器窗口**：
   ```python
   context = p.chromium.launch_persistent_context(
       user_data_dir="/path/to/chrome-profile",
       headless=False,  # ⚠️ 关键：必须可见，让用户能手动操作
   )
   ```
3. **告知用户**："网站 `xxx.com` 需要登录，请在打开的浏览器窗口中手动完成登录。"
4. **等待用户操作**：
   - 轮询检测登录状态（每3秒，超时120秒后询问用户）
   - 检测条件：URL回到文档页 / 页面出现文档内容 / 登录弹窗消失
5. **用户确认登录完成**：
   - 用户说"好了"、"登录完了"、"继续"或"已登录"
   - 或者自动检测到内容已加载
6. **恢复自动化**：继续在当前窗口中截图/下载，完成后关闭窗口

> 🎯 **优先策略**：如果该网站在 kill-doc 支持列表内（30+网站），直接用 kill-doc，完全跳过登录环节。

### 场景3：已安装 kill-doc 的浏览器（推荐）
1. 使用持久化 Chrome 用户数据目录（已预装 Tampermonkey + kill-doc）
2. 导航到文档页面
3. 等待 kill-doc 脚本加载并显示功能按钮
4. 依次点击：自动预览 → 停止预览 → 下载PDF/下载图片
5. 等待文件下载完成

### Playwright 持久化上下文配置

```python
from playwright.sync_api import sync_playwright

# 使用持久化上下文启动浏览器（支持Chrome扩展）
with sync_playwright() as p:
    context = p.chromium.launch_persistent_context(
        user_data_dir="/path/to/chrome-profile",  # 预装有Tampermonkey的用户数据目录
        channel="chromium",
        headless=False,  # 设为False以显示浏览器窗口（用户可手动登录）
        args=[
            "--disable-extensions-except=/path/to/tampermonkey",
            "--load-extension=/path/to/tampermonkey",
        ],
    )
    page = context.pages[0]
    page.goto("https://max.book118.com/...")
    # 等待kill-doc加载并操作...
```

### 常见问题排查

| 问题 | 解决方案 |
|------|-----------|
| kill-doc无功能按钮 | 需开启Tampermonkey开发者模式 |
| 下载文件不完整 | 按顺序(1)→(2)→(3)执行，等待完成再执行下一步 |
| PDF模糊 | 尝试下载图片格式自行合并，或调整浏览器缩放比例 |
| 原创力PPT下载失败 | 保持浏览器全屏，不要缩小 |
| 页面需要登录 | 切换到headed模式让用户手动登录 |
| 夸克自动预览不完全 | 手动滚动页面后下载 |

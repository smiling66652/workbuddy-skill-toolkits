# 二级：网页抓取管道

**适用场景**：用户需要抓取网页内容、提取正文、爬取数据

## 自动策略（无需手动选择）

1. **Stage 1** — 新闻/文章检测（URL模式 + Schema.org + 内容启发式评分）
2. **Stage 2** — 多策略抓取（curl → **CDP 直连** → pw.mjs(局部 Playwright) → scrapy，按可用性降级）
3. **Stage 3** — 清洗归一化（trafilatura 去样板、编码归一、分块）
4. **Stage 4** — 结构化元数据提取（作者/日期/分类/付费墙检测）
5. **Stage 5** — LLM 实体提取（**可选**，需 `OPENROUTER_API_KEY`；本机未配置此 key，跳过）

> **Stage 2 降级顺序已调整**：CDP 直连插在 Playwright 之前。它复用你已开的浏览器，不用拉起新实例，**还自带登录态**，比另起实例快且成功率高。
>
> ⚠️ **本机现实**：`scrapy`、`trafilatura`(系统 Python 有)、`requests` 等并非全部就绪。
> 跑之前先 `node scripts/doctor.mjs` 看「Python 抓取栈」那一段的实测结果，别照本页盲跑。

## 三级执行：工具选择

| 场景 | 推荐工具 | 原因 |
|------|------------|------|
| 静态HTML、RSS | `curl` / `requests` + `BeautifulSoup` | 快；先用它判断 HTML 里有没有正文 |
| 批量抓取（50+页） | `scrapy`（**本机未装**） | 并发；装：`pip install scrapy` |
| **需要登录态 / 静态层被拦 / 需交互** | **CDP 直连** | 继承登录态、真实浏览器环境 |
| SPA、JS渲染、懒加载（CDP 不可用时） | `node scripts/pw.mjs`（本地 playwright-cli，走系统 Edge） | 渲染完整 DOM，零安装 |
| 需要绕过 Cloudflare | 见 [反爬对抗](反爬对抗.md)（CDP 直连 → nodriver → curl_cffi） | 不再用未验证的付费方案 |
| 全部失败 | 标记为 `failed`，保存待重试 | — |

### CDP 直连抓取（首选）

```bash
# 前置检查（会确保 Proxy 已运行）
node "C:/Users/Matebook/.workbuddy/skills/联网工具箱/scripts/check-deps.mjs"

# 新建后台 tab（URL 走 POST body！）
curl -s -X POST --data-raw 'https://example.com' http://localhost:3456/new

# 滚动触发懒加载，再提取
curl -s "http://localhost:3456/scroll?target=ID&direction=bottom"

# 提取正文
curl -s -X POST "http://localhost:3456/eval?target=ID" \
  -d 'document.querySelector("article").innerText'

# 用完关闭自己创建的 tab
curl -s "http://localhost:3456/close?target=ID"
```

**页面就绪 ≠ 内容就绪**：`/new` 返回只代表文档基础加载完成。导航后必须用 `/eval` 检查目标内容；未出现则在 **15 秒**窗口内持续观察 URL/标题/DOM。

## 技术事实（写抓取脚本前必读）

- **已加载但未展示的内容**：轮播中非当前帧的图片、折叠区块的文字、懒加载占位元素——它们存在于 DOM 但用户不可见。以数据结构（容器、属性、节点关系）为单位思考，可直接触达
- **选择器不可跨越的边界**：Shadow DOM 的 `shadowRoot`、iframe 的 `contentDocument`。eval 递归遍历可一次穿透所有层级，适合快速了解未知页面的完整结构
- **滚动才触发懒加载**：`/scroll` 到底部才让未进入视口的图片完成加载。**提取图片 URL 前先滚动**，否则会漏
- **密集开页面会触发反爬**：短时间内大量 `/new` 可能触发站点风控，注意节流
- **"内容不存在"未必是真的**：也可能是 URL 缺失必要参数或触发反爬。先怀疑访问方式，再怀疑内容

## 媒体与视频提取

- **内容在图片里** → 用 `/eval` 从 DOM 直接拿图片 URL，再定向读取，比全页截图精准得多
- **视频** → `/eval` 操控 `<video>` 元素（获取时长、seek 到任意时间点、播放/暂停），配合 `/screenshot` 采帧，做离散采样分析
- 公开资源提取 URL 后直接下载读取；需要登录态的才在浏览器内 navigate + screenshot

## 付费墙处理

- 硬付费墙 → 提取预览（标题/导语/元数据），标记 `paywall: "hard"`
- 软付费墙 → 用 CDP `/eval` 移除叠加层，揭示正文
- 无付费墙 → 正常处理

### 中文文档网站付费墙策略

针对百度文库、原创力(Book118)、夸克文档、道客巴巴、豆丁网等中文文档网站，分层策略：

**第1层：CDP 直连 + 已登录态**
你已在该站登录时，CDP 直接继承 Cookie，无需任何绕过动作。

**第2层：kill-doc Tampermonkey脚本**
- 安装 Tampermonkey + kill-doc 脚本后自动处理
- 详情参见 `付费文档下载.md`

**第3层：截图拼接**
```python
# Playwright 或 CDP /screenshot 逐屏截图
for i in range(total_pages):
    page.screenshot(path=f"page_{i}.png")
    page.evaluate("window.scrollBy(0, window.innerHeight)")
```

**第4层：有头浏览器 + 手动登录**
- 启动 headed 浏览器，通知用户手动登录，登录后继续自动化

## 使用 requests + BeautifulSoup（轻量）

```python

response = requests.get("https://example.com")
response.encoding = 'utf-8'
soup = BeautifulSoup(response.text, 'html.parser')
print(soup.get_text())
```

## 故障排查

| 问题 | 解决方案 |
|------|-----------|
| 请求被拦截（403 / 挑战页） | 升级到 CDP 直连（有登录态优先），再走 [反爬对抗](反爬对抗.md) |
| CDP 连接失败 | 跑 `node "C:/Users/Matebook/.workbuddy/skills/联网工具箱/scripts/check-deps.mjs"`，确认浏览器已开远程调试端口 |
| 提取内容为空 | ①先 `curl` 看 HTML 里有没有正文 ②是否需先 `/scroll` 触发懒加载 ③是否在 Shadow DOM / iframe 内 |
| 图片/视频漏抓 | 先滚动到底再提取 URL |
| 需要浏览器但没有 CDP | 用 `node scripts/pw.mjs open <url>`（本地 playwright，走系统 Edge，零安装） |
| Python 包缺失 | `venv python -m pip install <包> -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 付费墙无法绕过 | 用 CDP 继承登录态，或见 `付费文档下载.md` |
| 编码错误 | 使用 `response.encoding = 'utf-8'` |
| curl 报 `CRYPT_E_NO_REVOCATION_CHECK` | 校园网环境，加 `--ssl-no-revoke` |

# 二级：网页抓取管道

**适用场景**：用户需要抓取网页内容、提取正文、爬取数据

## 自动策略（无需手动选择）

1. **Stage 1** — 新闻/文章检测（URL模式 + Schema.org + 内容启发式评分）
2. **Stage 2** — 多策略抓取（requests → Playwright → Scrapy，自动降级）
3. **Stage 3** — 清洗归一化（trafilatura去样板、编码归一、分块）
4. **Stage 4** — 结构化元数据提取（作者/日期/分类/付费墙检测）
5. **Stage 5** — LLM实体提取（可选，需 OPENROUTER_API_KEY）

## 三级执行

**判断用哪个方法**：

| 场景 | 推荐工具 | 原因 |
|------|------------|------|
| 静态HTML、RSS | `requests` + `BeautifulSoup` | 快 |
| 批量抓取（50+页） | `scrapy` | 并发 |
| SPA、JS渲染、懒加载 | `playwright` | 渲染完整DOM |
| 需要绕过 Cloudflare | `human-browser` | 住宅IP+iPhone指纹 |
| 全部失败 | 标记为 `failed`，保存待重试 | — |

**三级执行示例**：

```bash
# 让 Agent 直接访问 URL，按五阶段管道处理
# Agent 会自动选择最轻量的方法，只在需要时升级

# 如需绕过 Cloudflare，使用 Human Browser
clawhub install human-browser
human-browser open https://example.com
human-browser act "click the Login button"
```

## 付费墙处理

- 硬付费墙 → 提取预览（标题/导语/元数据），标记 `paywall: "hard"`
- 软付费墙 → 用Playwright移除叠加层，揭示正文
- 无付费墙 → 正常处理

## 使用 scrapy 批量抓取

```bash
# 创建 scrapy 项目
scrapy startproject myproject
cd myproject

# 生成蜘蛛
scrapy genspider example example.com

# 运行蜘蛛
scrapy crawl example
```

## 使用 requests + BeautifulSoup（轻量）

```python
import requests
from bs4 import BeautifulSoup

response = requests.get("https://example.com")
soup = BeautifulSoup(response.text, 'html.parser')
print(soup.get_text())
```

## 故障排查

| 问题 | 解决方案 |
|------|-----------|
| requests 被拦截 | 换用 playwright 或 human-browser |
| playwright 超时 | 检查网络连接，或换用 scrapy |
| 付费墙无法绕过 | 使用 human-browser（住宅IP） |
| 编码错误 | 检查网页编码，使用 `response.encoding = 'utf-8'` |

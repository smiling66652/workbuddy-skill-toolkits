# WorkBuddy Skill 工具箱套件合集

> 本仓库收录了为 WorkBuddy AI 助手整合的 6 大工具箱 Skill 套件 + 1 个元技能，覆盖开发、文档、联网、安全、知识、AI 六大场景。

## 工具箱列表

| 工具箱 | 功能说明 | 集成最佳工具 |
|--------|----------|--------------|
| 开发工具箱 | 代码搜索/审查/测试/GitHub 操作 | gh CLI、Semgrep、pytest、Flutter CLI、Android SDK |
| 文档工具箱 | PDF/Word/Excel/PPT/Markdown 互转 | MinerU、MarkItDown、pypandoc、python-docx、openpyxl |
| 联网工具箱 | 搜索/抓取/浏览器自动化/内容总结 | Playwright CLI、Agent Browser、MiniMax CLI、cli-anything-hub |
| 安全工具箱 | 漏洞扫描/渗透测试/安全审计 | sqlmap、nmap、OWASP ZAP、Grype、Trivy |
| 知识工具箱 | 知识库管理/语义搜索/IMA 集成 | IMA 知识库 MCP、TrainKB Skill |
| AI 工具箱 | 本地模型/云端 API/混合调用 | Ollama、OpenAI API、DeepSeek API、LM Studio |

## 元技能：skill-integrator

三级层级结构方法论：
1. **一级**：分析用户需求，确定工具类型（开发/文档/联网/安全/知识/AI）
2. **二级**：从同类工具中选择最佳方案（性能/易用性/兼容性）
3. **三级**：执行指令并返回结果

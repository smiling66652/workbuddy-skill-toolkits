## 工作原理与风险提示（如实告知用户）

edge-tts 调用**微软 Edge 浏览器的在线语音合成服务**（免费、无需密钥），
属社区对微软服务的非官方调用：微软不承诺可用性，接口随时可能变化。
本技能定位为零成本轻量方案，重要生产链路请备选离线 TTS。

## 移植方式

- `SKILL.md`：按官方 README 组织中文工作流（安装/CLI/Python API/中文音色表/常见坑）
- `scripts/tts_batch.py`：**本技能新增的批量封装**

## 新增内容（自研部分，仅脚本层）

- 批量目录/多文件、长文本自动分段合成（防超时）后拼接、--subtitle 输出 VTT、dry-run
- 依赖缺失中文安装指引

## 中文环境适配

1. 音色表按中文场景整理（晓晓/云希/云扬/东北话/粤语/台湾腔），默认 zh-CN-XiaoxiaoNeural
2. 长文分段阈值按中文 1800 字设计；字幕按中文行估算时长
3. 商用边界提醒写入 SKILL.md 与本文件

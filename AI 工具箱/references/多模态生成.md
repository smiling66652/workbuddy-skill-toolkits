# 二级：多模态生成

**适用场景**：用户需要生成视频、3D模型、图片特效等多模态内容

---

## 工具对比

| 工具 | 支持模态 | 速度 | 费用 | 推荐场景 |
|------|---------|------|------|------------|
| **MiniMax CLI** | 文生视频、图生视频 | 慢（分钟级） | 按量付费 | 快速原型（推荐） |
| **Genmo** | 文生视频、图生视频 | 中 | 订阅制 | 高质量视频 |
| **Luma Dream Machine** | 文生视频、图生视频 | 快 | 按生成次数 | 快速迭代 |
| **OpenAI Sora** | 文生视频 | 慢 | 订阅制（ChatGPT Plus） | 最长60秒视频 |
| **Meshy** | 文生3D、图生3D | 中 | 免费额度+订阅 | 游戏资产（推荐） |
| **Luma Genesis** | 文生3D | 慢 | 按生成次数 | 高精度3D模型 |

## 三级执行：MiniMax CLI（推荐，视频生成）

**触发词**：生成视频、做视频、图片变视频

### 安装

```bash
npm install -g mmx-cli
```

### 使用

```bash
# 文生视频
mmx video generate --prompt "Ocean waves at sunset" --download sunset.mp4

# 异步生成（不等待结果）
mmx video generate --prompt "A robot painting" --async

# 查询指定任务状态
mmx video task get --task-id 123456

# 通过文件ID下载视频
mmx video download --file-id 176844028768320 --out video.mp4
```

### 参数说明

- `--prompt`：视频描述（英文效果更好）
- `--download`：生成后自动下载
- `--async`：异步生成，返回任务ID
- `--ratio`：视频比例（16:9、9:16、1:1）

## 三级执行：Meshy（3D模型生成）

**触发词**：生成3D模型、做3D、图片转3D

### 安装

```bash
# 方法1：使用Meshy Web（无需安装）
# 访问 https://www.meshy.ai/

# 方法2：使用Meshy API
pip install meshy-sdk
```

### 使用（API）

```python
from meshy import MeshyClient

client = MeshyClient(api_key="YOUR_API_KEY")

# 文生3D
task = client.tasks.create(
    mode="text-to-3d",
    prompt="A cute cat",
    art_style="realistic",
)
print(f"任务ID: {task.id}")

# 查询任务状态
task = client.tasks.get(task.id)
if task.status == "SUCCEEDED":
    print(f"模型下载链接: {task.model_url}")

# 图生3D
task = client.tasks.create(
    mode="image-to-3d",
    image_url="https://example.com/image.png",
    art_style="cartoon",
)
```

### 使用（Web）

1. 访问 https://www.meshy.ai/
2. 选择 "Text to 3D" 或 "Image to 3D"
3. 输入描述或上传图片
4. 选择风格（Realistic、Cartoon、Low Poly等）
5. 点击生成，等待完成
6. 下载模型（GLB/OBJ/FBX格式）

## 三级执行：Luma Dream Machine（快速视频生成）

**触发词**：快速生成视频、Dream Machine

### 使用（Web）

1. 访问 https://lumalabs.ai/dream-machine
2. 输入文字描述或上传图片
3. 点击生成
4. 等待完成（通常1-5分钟）
5. 下载视频

### 使用（API）

```bash
# 需要 LUMA_API_KEY
curl -X POST "https://api.lumalabs.ai/dream-machine/v1/generations" \
  -H "Authorization: Bearer $LUMA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A cat walking in the rain",
    "image_url": "https://example.com/cat.png"
  }'
```

## 使用建议

1. **快速视频原型** → MiniMax CLI（mmx）
2. **高质量视频** → Genmo 或 Luma Dream Machine
3. **最长视频（60秒）** → OpenAI Sora（需ChatGPT Plus订阅）
4. **3D模型（游戏资产）** → Meshy
5. **高精度3D** → Luma Genesis

---

## 注意事项

- **成本控制**：视频/3D生成按次/按量付费，注意预算
- **生成时间**：视频生成通常需要几分钟到几十分钟
- **格式支持**：视频通常为MP4，3D模型通常为GLB/OBJ/FBX
- **版权问题**：生成的视频/3D模型版权归属需确认
- **提示词质量**：英文提示词效果远好于中文

# 二级：语音转文字（Whisper）

**适用场景**：用户需要转录音频、语音转文字、视频字幕提取

---

## 工具对比

| 工具 | 准确率 | 速度 | 费用 | 推荐场景 |
|------|--------|------|------|------------|
| **OpenAI Whisper API** | ⭐⭐⭐⭐⭐ | 中 | 按分钟付费 | 高精度转录（推荐） |
| **Whisper 本地（faster-whisper）** | ⭐⭐⭐⭐⭐ | 快 | 免费 | 本地部署/批量 |
| **Whisper 本地（官方）** | ⭐⭐⭐⭐⭐ | 慢 | 免费 | 精准控制 |
| **MiniMax CLI（语音合成）** | N/A | 快 | 按量付费 | 文字转语音（TTS） |

> ⚠️ **注意**：MiniMax CLI 的 `speech` 模块是 **TTS（文字转语音）**，不是 STT（语音转文字）

---

## 三级执行：OpenAI Whisper API（推荐）

**触发词**：转录音频、语音转文字、提取视频字幕、Whisper

### 前置条件

需要 `OPENAI_API_KEY`

### 使用

```python
import openai
import os

client = openai.OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# 转录音频文件
audio_file = open("audio.mp3", "rb")
transcript = client.audio.transcriptions.create(
    model="whisper-1",
    file=audio_file,
    language="zh",  # 可选，指定语言可提高准确率
)
print(transcript.text)

# 翻译非英音频到英文
audio_file = open("chinese_audio.mp3", "rb")
translation = client.audio.translations.create(
    model="whisper-1",
    file=audio_file,
)
print(translation.text)
```

### 支持格式

- 音频：mp3, mp4, mpeg, mpga, m4a, wav, webm
- 文件大小：≤ 25 MB
- 语言：自动检测，或手动指定

---

## 三级执行：Whisper 本地（faster-whisper，推荐本地方案）

**触发词**：本地转录、批量转录、免费转录

### 安装

```bash
pip install faster-whisper
```

### 使用

```python
from faster_whisper import WhisperModel

# 加载模型（首次运行会自动下载）
model = WhisperModel("base", device="cuda", compute_type="float16")
# 可选模型：tiny, base, small, medium, large-v2, large-v3

# 转录音频
segments, info = model.transcribe("audio.mp3", language="zh")

print(f"检测到语言: {info.language} (概率: {info.language_probability:.2f})")

for segment in segments:
    print(f"[{segment.start:.2f}s -> {segment.end:.2f}s] {segment.text}")
```

### 模型大小对比

| 模型 | 参数量 | 相对速度 | 准确率 | 显存需求 |
|------|--------|----------|--------|----------|
| tiny | 39M | 32x | 低 | ~1GB |
| base | 74M | 16x | 中 | ~1GB |
| small | 244M | 6x | 高 | ~2GB |
| medium | 769M | 2x | 很高 | ~5GB |
| large-v3 | 1550M | 1x | 最高 | ~10GB |

## 三级执行：Whisper 本地（官方）

### 安装

```bash
pip install -U openai-whisper
# 需要 ffmpeg
# Windows: choco install ffmpeg
# Mac: brew install ffmpeg
```

### 使用

```python
import whisper

# 加载模型
model = whisper.load_model("base")  # tiny, base, small, medium, large

# 转录音频
result = model.transcribe("audio.mp3", language="zh")
print(result["text"])

# 翻译到英文
result = model.transcribe("chinese_audio.mp3", task="translate")
print(result["text"])
```

---

## 使用建议

1. **高精度/小文件** → OpenAI Whisper API
2. **批量/大文件/隐私** → faster-whisper（本地）
3. **指定语言** → 设置 `language="zh"` 可大幅提高准确率和速度
4. **长音频（>1小时）** → 用 faster-whisper 分段处理
5. **视频文件** → 先用 ffmpeg 提取音频，再转录

---

## 注意事项

- **中文音频** → 指定 `language="zh"` 非常重要
- **文件大小限制** → OpenAI API 限制 25MB，大文件需切片
- **GPU加速** → 本地运行推荐使用GPU（CUDA），CPU非常慢
- **标点符号** → Whisper会自动添加标点，但可能不准确

# 二级：模型使用统计（model-usage / CodexBar）

**适用场景**：用户需要查看模型用量、token统计、成本分析

---

## 工具对比

| 工具 | 统计维度 | 可视化 | 推荐场景 |
|------|---------|----------|------------|
| **model-usage** | 模型/token/成本 | ❌ | 命令行快速查看 |
| **CodexBar** | 模型/时间/成本 | ✅（图表） | 可视化分析 |

---

## 三级执行：model-usage（推荐）

**触发词**：模型用量、token统计、查看使用量、成本分析

### 安装

```bash
pip install model-usage
```

### 使用

```bash
# 查看所有模型用量
model-usage

# 按模型筛选
model-usage --model gpt-4

# 按日期范围筛选
model-usage --start 2025-01-01 --end 2025-12-31

# 导出为JSON
model-usage --output json --file usage.json

# 查看token消耗详情
model-usage --detail
```

### 输出示例

```
模型用量统计（2025-01-01 至 2025-12-31）

模型             Token用量        成本(USD)
----------------------------------------------
gpt-4           1,234,567       $38.52
gpt-3.5-turbo   5,678,901       $28.39
claude-3-opus    987,654         $29.63

总计            7,901,122       $96.54
```

## 三级执行：CodexBar（可视化）

**触发词**：模型用量图表、token可视化、成本趋势

### 安装

```bash
pip install codexbar
```

### 使用

```bash
# 生成用量图表
codexbar --output chart.png

# 指定时间范围
codexbar --start 2025-01-01 --end 2025-12-31 --output yearly.png

# 按模型分组
codexbar --group-by model --output by_model.png

# 按日期分组（查看趋势）
codexbar --group-by date --output trend.png
```

---

## 使用建议

1. **快速查看用量** → model-usage（命令行）
2. **可视化分析** → CodexBar（图表）
3. **导出数据** → model-usage --output json
4. **成本优化** → 查看哪个模型消耗最多token/cost
5. **定期监控** → 可以设置定时任务，每日/每周统计

---

## 注意事项

- **数据来源**：需要LLM API调用时记录用量（通常API会返回token使用量）
- **存储位置**：用量数据通常存储在本地数据库或日志文件中
- **隐私保护**：用量数据可能包含敏感信息，注意保护

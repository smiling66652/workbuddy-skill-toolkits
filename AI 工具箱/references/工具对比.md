# 工具对比

**适用场景**：需要选择最佳工具时读取。先按「场景 → 候选 → 决策依据」三步走，不要凭印象选。

---

## 场景 → 候选

| 场景 | 首选 | 备选 | 决策依据 |
|---|---|---|---|
| 文生图 | 内置 ImageGen | 本地 SD / ComfyUI | 有网、要快 → ImageGen；离线、要风格可控 → 本地 |
| 图生图 / 去水印 / 消除 | 内置图像处理 | OpenCV inpaint（本地） | 要求像素级精确擦除 → OpenCV inpaint，见 `image-to-editable-pptx` |
| 文生视频 | 内置 VideoGen | — | 短片段、快速出片用内置 |
| 文生 3D | 3D 模型生成 skill | — | 基于模板，不支持任意建模 |
| 语音转文字 | edge-tts 反向 / Whisper 系 | 讯飞、OpenAI Whisper API | 中文长音频 → 本地 Whisper；短句、要快 → API |
| 自动研究 | 联网工具箱 + 内置搜索 | agentic_search（金融限定） | 金融话题才用 agentic_search，否则普通搜索 |
| 模型统计 | 本地 Ollama / LM Studio 日志 | API 用量接口 | 本地模型看 AIModels 目录日志 |
| 多模态生成 | 见 `references/多模态生成.md` | — | — |

---

## 通用决策规则

1. **先判断有没有网**。离线场景一律走本地（Ollama / LM Studio / OpenCV / Whisper）。
2. **先判断要不要可复现**。要可复现、可批量的，优先选有 CLI / API 的，不选只能点界面的。
3. **先判断精度要求**。像素级、版式级要求 → 本地脚本；内容级要求 → 生成式模型。
4. **不要为了用新工具而用**。内置能力够用时优先内置，省一轮调试。
5. **选完要验证**。工具跑通后把结论写回本页，避免下次重新纠结。

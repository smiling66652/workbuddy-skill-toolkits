# 二级：自动研究优化（autoresearch）

**适用场景**：用户需要自动优化内容、生成多个变体、评分筛选最优版本

---

## 工具对比

| 工具 | 变体数量 | 评分机制 | 速度 | 推荐场景 |
|------|----------|----------|------|------------|
| **autoresearch** | 50+ | LLM自评 | 中 | 内容优化（推荐） |
| **promptperfect** | 10-20 | 规则+LLM | 快 | Prompt优化 |
| **人工筛选** | 无限 | 人工 | 慢 | 高精度要求 |

---

## 三级执行：autoresearch（推荐）

**触发词**：自动优化、生成变体、研究这个话题、优化这个内容

### 安装

```bash
pip install autoresearch
```

### 使用

```python
from autoresearch import AutoResearcher

# 初始化
researcher = AutoResearcher(
    topic="如何提高工作效率",
    num_variants=50,  # 生成50个变体
    model="gpt-4",     # 使用的LLM模型
)

# 执行研究（自动生成变体+评分）
results = researcher.run()

# 获取最优结果
best_result = results.top_k(1)[0]
print(f"最优变体: {best_result.content}")
print(f"评分: {best_result.score}")

# 获取前5个结果
top_5 = results.top_k(5)
for i, result in enumerate(top_5, 1):
    print(f"第{i}名 (评分: {result.score:.2f}): {result.content[:100]}...")
```

### 工作流程

1. **生成变体**：根据主题生成 50+ 个不同角度的变体
2. **评分筛选**：用LLM对每个变体评分（相关性、创新性、可行性等）
3. **返回最优**：按评分排序，返回前N个结果

## 三级执行：Prompt优化（promptperfect）

**触发词**：优化prompt、改进提示词、prompt工程

### 使用

```python
# 方法1：使用 autoresearch 的 prompt 优化功能
from autoresearch import PromptOptimizer

optimizer = PromptOptimizer(model="gpt-4")
optimized_prompt = optimizer.optimize(
    original_prompt="写一篇关于AI的文章",
    num_variants=10,
)
print(f"优化后的prompt: {optimized_prompt}")

# 方法2：手动迭代优化
# 让LLM评估并改进prompt
```

---

## 使用建议

1. **内容优化** → autoresearch（生成50+变体）
2. **Prompt工程** → autoresearch 的 PromptOptimizer
3. **研究话题** → autoresearch（自动搜集+整理）
4. **批量生成** → 设置 `num_variants=100+`（注意成本）

---

## 注意事项

- **成本控制**：生成50+变体会消耗大量token，注意预算
- **评分主观性**：LLM自评可能存在偏差，关键内容建议人工复核
- **主题明确性**：主题越明确，生成的变体质量越高
- **模型选择**：`gpt-4` 评分更准确，`gpt-3.5-turbo` 更便宜

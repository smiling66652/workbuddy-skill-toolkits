# 二级：文生图

**适用场景**：用户需要生成图片、AI画画、制作logo、创意图像

---

## 工具对比

| 工具 | 质量 | 速度 | 费用 | 推荐场景 |
|------|------|------|------|------------|
| **OpenAI DALL-E 3** | ⭐⭐⭐⭐⭐ | 中（10-30s） | 按张付费 | 高质量图片（推荐） |

## 三级执行：OpenAI DALL-E 3（推荐）

**触发词**：生成图片、画一张、AI画画、做个logo

### 前置条件

需要 `OPENAI_API_KEY`

### 使用

```python
import openai
import os

client = openai.OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# 基础文生图
response = client.images.generate(
    model="dall-e-3",
    prompt="A cat in a spacesuit, digital art",
    n=1,
    size="1024x1024",
    quality="hd",  # 或 "standard"
    style="vivid",   # 或 "natural"
)
image_url = response.data[0].url
print(f"图片URL: {image_url}")

# 保存图片
import requests
img_data = requests.get(image_url).content
with open("output.png", "wb") as f:
    f.write(img_data)
```

### 参数说明

- `size`：`1024x1024`（方形）、`1792x1024`（横版）、`1024x1792`（竖版）
- `quality`：`hd`（高清，贵）、`standard`（标准，便宜）
- `style`：`vivid`（鲜艳，默认）、`natural`（自然）
- `n`：生成数量（DALL-E 3 只支持 `n=1`）

## 三级执行：MiniMax CLI（快速/批量）

**触发词**：快速生成图片、批量生成、mmx生成

### 安装

```bash
npm install -g mmx-cli
```

### 使用

```bash
# 基础文生图
mmx image "A cat in a spacesuit"

# 生成3张16:9比例的图片
mmx image generate --prompt "A cat" --n 3 --aspect-ratio 16:9

# 指定输出目录
mmx image generate --prompt "Logo" --out-dir ./output/
```

## 三级执行：Stable Diffusion（本地）

**触发词**：本地生成图片、免费生成图片、隐私图片生成

### 安装

```bash
# 方法1：使用 diffusers（推荐）
pip install diffusers transformers accelerate

# 方法2：使用 AUTOMATIC1111 WebUI（图形界面）
# 访问 https://github.com/AUTOMATIC1111/stable-diffusion-webui
```

### 使用（diffusers）

```python
from diffusers import StableDiffusionPipeline
import torch

# 加载模型（首次运行会自动下载）
pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    torch_dtype=torch.float16,
).to("cuda")  # 需要NVIDIA GPU

# 生成图片
image = pipe(
    prompt="A cat in a spacesuit, digital art",
    num_inference_steps=50,
    guidance_scale=7.5,
).images[0]

# 保存
image.save("output.png")
```

## 使用建议

1. **高质量图片** → OpenAI DALL-E 3
2. **快速/批量生成** → MiniMax CLI（mmx）
3. **本地/免费/隐私** → Stable Diffusion（需要GPU）
4. **艺术风格** → Midjourney API（订阅制）
5. **中文prompt** → 用翻译工具先转为英文（效果更好）

---

## 注意事项

- **Prompt质量**：英文prompt效果远好于中文
- **版权问题**：AI生成图片的版权归属需确认
- **内容审核**：OpenAI会拒绝不合规的prompt
- **成本控制**：DALL-E 3 标准质量约$0.04/张，高清$0.08/张

# 二级：目标追踪

**适用场景**：追踪目标/写日记/里程碑/HTML仪表盘

---

## 工具对比

| 工具 | 功能 | 速度 | 推荐场景 |
|------|------|------|------------|
| **goal-tracker skill** | 目标追踪/日记/里程碑 | 快 | 个人目标管理（推荐） |
| **手动Markdown** | 简单记录 | 非常快 | 轻量使用 |

---

## 三级执行：goal-tracker skill（推荐）

**触发词**：追踪目标、写日记、里程碑、目标仪表盘

### 使用

```
# 让Agent调用 goal-tracker skill
# Agent会自动使用 goal-tracker 记录目标/日记/里程碑
```

---

## 三级执行：手动Markdown（轻量）

**触发词**：简单记录目标、写日记

### 创建目标文件

```markdown
# 目标追踪

## 2026年目标

### 目标1：保研成功
- 状态：进行中
- 截止日期：2026-09-01
- 里程碑：
  - [x] 2026-03-01：完成所有课程学习
  - [ ] 2026-06-01：参加夏令营
  - [ ] 2026-09-01：获得保研资格

### 目标2：完成刷题项目
- 状态：进行中
- 截止日期：2026-12-31
- 里程碑：
  - [x] 2026-05-01：SurveyKing上线
  - [ ] 2026-08-01：yf-exam-lite完成
  - [ ] 2026-12-31：xzs-mysql完成
```

### 写日记

```markdown
# 2026-06-01 日记

## 今日完成
- 整合了 WorkBuddy skills
- 修复了自动停止问题

## 明日计划
- 继续优化 skills
- 测试新配置

## 感想
今天效率很高，继续加油！
```

---

## 使用建议

1. **完整目标管理** → goal-tracker skill
2. **轻量记录** → 手动Markdown
3. **定期回顾** → 每周/每月回顾目标文件和日记
4. **可视化** → 用 goal-tracker 生成HTML仪表盘
5. **备份** → 定期备份目标文件和日记

---

## 注意事项

- **坚持记录**：目标追踪和日记需要持续记录才有效果
- **定期回顾**：每周/每月回顾目标，调整计划
- **可视化**：用图表/仪表盘可视化进度，更有动力
- **分享**：和目标相同的人分享进度，互相督促

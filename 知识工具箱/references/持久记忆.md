# 二级：持久记忆

**适用场景**：让AI记住某事（跨会话）、用户偏好设置、项目上下文

---

## 工具对比

| 工具 | 作用域 | 自动读取 | 推荐场景 |
|------|---------|---------|------------|
| **项目级 MEMORY.md** | 当前项目 | ✅ 每次对话 | 项目约定/架构决策 |
| **用户级 MEMORY.md** | 跨项目 | ✅ 每次对话 | 用户偏好/习惯 |
| **日志 YYYY-MM-DD.md** | 当日 | ❌ 手动读取 | 每日工作记录 |

---

## 三级执行：写入记忆

**触发词**：记住这个、别忘了、我的偏好是、以后都这样、帮我记一下

### 项目级记忆（推荐）

```bash
# 追加到项目记忆
echo "## 用户偏好\n- 使用简体中文回答\n- 代码用 Python" >> C:/.workbuddy/memory/MEMORY.md
```

### 用户级记忆（跨项目）

```bash
# 追加到用户级记忆
echo "## 用户偏好\n- 双设备：MateBook + Y7000P\n- 家乡：宣城" >> C:/Users/Matebook/.workbuddy/MEMORY.md
```

### 每日日志

```bash
# 追加到今日日志
today=$(date +%Y-%m-%d)
echo "## 完成工作\n- 整合了 skills" >> C:/.workbuddy/memory/${today}.md
```

---

## 三级执行：读取记忆

**触发词**：你记得吗、之前说过、上次做了什么

### 自动读取（无需手动操作）

WorkBuddy 会在每次对话开始时自动读取：
- 项目级 `MEMORY.md`
- 用户级 `MEMORY.md`
- 今日日志 `YYYY-MM-DD.md`

### 手动读取（需要时）

```bash
# 读取项目记忆
cat C:/.workbuddy/memory/MEMORY.md

# 读取用户级记忆
cat C:/Users/Matebook/.workbuddy/MEMORY.md

# 读取特定日期日志
cat C:/.workbuddy/memory/2026-06-01.md
```

---

## 使用建议

1. **项目约定/架构决策** → 写入项目级 `MEMORY.md`
2. **用户偏好/习惯** → 写入用户级 `MEMORY.md`
3. **每日工作记录** → 写入 `YYYY-MM-DD.md`
4. **重要事实** → 立即写入，不要等会话结束
5. **读取记忆** → 通常自动完成，无需手动读取

## 三级执行：CrossRef API（自动获取引用信息）

**触发词**：自动获取引用信息、DOI转引用

### 安装

```bash
pip install crossrefapi
```

### 使用

```python
from crossref.restful import Works

works = Works()

# 通过DOI获取文献信息
doi = "10.1145/358618.3586246"
work = works.doi(doi)
print(f"标题：{work['title'][0]}")
print(f"作者：{', '.join([author['given'] + ' ' + author['family'] for author in work['author']])}")
print(f"期刊：{work['container-title'][0]}")
print(f"出版年：{work['published-print']['date-parts'][0][0]}")

# 生成APA格式引用
def format_apa(work):
    authors = ', '.join([f"{author['family']}, {author['given'][0]}." for author in work['author'][:7]])
    if len(work['author']) > 7:
        authors = authors + " et al."
    year = work['published-print']['date-parts'][0][0]
    title = work['title'][0]
    journal = work['container-title'][0]
    volume = work.get('volume', '')
    issue = work.get('issue', '')
    pages = work.get('page', '')
    doi = work['DOI']
    
    citation = f"{authors} ({year}). {title}. {journal}"
    if volume:
        citation += f", {volume}"
    if issue:
        citation += f"({issue})"
    if pages:
        citation += f", {pages}"
    citation += f". https://doi.org/{doi}"
    return citation

apa_citation = format_apa(work)
print(f"APA格式：{apa_citation}")
```

## 三级执行：手动编辑（轻量）

**触发词**：手动加参考文献、简单引用

### APA格式示例

```
作者姓, 名字首字母. (出版年). 文章标题. 期刊名, 卷(期), 页码. https://doi.org/xx.xxxx/xxxxx
```

示例：
```
Zhang, S. (2025). AI-assisted learning in mechanical engineering education. Journal of Engineering Education, 45(3), 123-145. https://doi.org/10.1145/358618.3586246
```

### MLA格式示例

```
作者姓, 名字. "文章标题." 期刊名, 卷, 期, 出版年, 页码.
```

示例：
```
Zhang, San. "AI-assisted learning in mechanical engineering education." Journal of Engineering Education, vol. 45, no. 3, 2025, pp. 123-145.
```

### Chicago格式示例

```
作者姓, 名字. "文章标题." 期刊名 卷, 期 (出版年): 页码. https://doi.org/xx.xxxx/xxxxx.
```

示例：
```
Zhang, San. "AI-assisted learning in mechanical engineering education." Journal of Engineering Education 45, no. 3 (2025): 123-145. https://doi.org/10.1145/358618.3586246.
```

### GB/T 7714格式示例

```
[1] 作者. 文章标题[J]. 期刊名, 出版年, 卷(期): 页码.
```

示例：
```
[1] 张三. AI辅助机械工程教育[J]. 工程教育杂志, 2025, 45(3): 123-145.
```

## 使用建议

1. **完整引用管理** → citation-manager skill
2. **自动获取引用信息** → CrossRef API
3. **简单引用** → 手动编辑
4. **引用格式选择** → 根据期刊/学校要求选择（APA/MLA/Chicago/GB-T）
5. **DOI优先** → 有DOI的文献优先用DOI生成引用

---

## 注意事项

- **引用格式准确性**：不同期刊/学校对引用格式要求不同，仔细检查
- **DOI重要性**：DOI是数字对象唯一标识符，优先使用
- **多个作者**：APA格式超过7个作者用"et al."
- **中文文献**：中文文献引用格式遵循GB/T 7714
- **定期更新**：文献信息可能更新，定期用DOI重新获取

# 三级层级结构模板

> 每个整合后的 skill 必须采用三级结构。

## 结构说明

```
一级：需求分析（判断用户要做什么）
  ↓
二级：工具选择（根据需求选择最佳工具，见对比表）
  ↓
三级：执行指令（调用工具并返回结果）
```

**为什么**：用户说一句话，AI 先理解意图（一级），再选工具（二级），最后执行（三级）。结构清晰，不易出错。

---

## references/ 目录规范

| 项目 | 规则 |
|------|------|
| 文件大小 | 每个文件 ≤ 4000 字符 |
| 命名 | `references/二级功能名.md` |
| 内容 | 只写该功能的详细用法、示例、API 文档 |
| 引用 | SKILL.md 中用 `详见 references/XXX.md` 引用 |

**为什么**：SKILL.md 保持精简（快速加载），详细文档按需读取（节省 tokens）。

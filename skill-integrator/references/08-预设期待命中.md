# 预设期待命中

> 在 SKILL.md 中**预先定义用户可能的期待**，当用户输入匹配时直接命中，让用户感觉"它懂我"。

---

## 设计思路

| 用户输入模式 | 直接命中 | 说明 |
|-------------|------------|------|
| "搜索 XXX" | 一级→搜索需求 → 二级→智能搜索 → 三级→执行 | 无需询问 |
| "抓取这个页面" | 一级→抓取需求 → 二级→网页抓取 → 三级→执行 | 自动选择最优方法 |
| "打开浏览器点击XXX" | 一级→自动化需求 → 二级→Playwright → 三级→执行 | 支持登录态 |

**效果**：用户感觉"它懂我"，不需要反复解释。

## 预设期待命中的设计原则

| 原则 | 说明 |
|------|------|
| **覆盖高频场景** | 用户最常说的 5-10 句话 |
| **直接命中，不询问** | 无需用户确认，直接执行 |
| **触发词加粗** | 醒目，易识别 |
| **说明简洁** | 一句话说明为什么这样设计 |

## 如何设计预设期待命中

### Step 1：列出用户可能说的话

```
用户可能说：
- "搜索 XXX"
- "查一下 XXX"
- "找资料"
- "抓取这个页面"
- "打开网页"
- "点击 XXX"
- "总结这个文章"
- "生成图片"
```

### Step 2：映射到三级结构

```
"搜索 XXX" → 一级：搜索需求 → 二级：智能搜索 → 三级：执行
"抓取这个页面" → 一级：抓取需求 → 二级：网页抓取 → 三级：执行
```

### Step 3：写入 SKILL.md

```markdown
## 预设期待命中

| 用户输入模式 | 直接命中 | 说明 |
|-------------|------------|------|
| "搜索 XXX" | 一级→搜索需求 → 二级→智能搜索 → 三级→执行 | 无需询问 |
```

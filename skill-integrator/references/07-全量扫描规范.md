# 全量扫描规范

> 整合前必须确认**所有相关 skills** 都已找到，不遗漏任何一个。

---

## 扫描步骤

### Step 1：按名称搜索

```bash
# 列出所有 skills
ls "C:/Users/Matebook/.workbuddy/skills/" | sort

# 按关键词搜索相关 skills
ls "C:/Users/Matebook/.workbuddy/skills/" | grep -i "关键词"
```

### Step 2：按内容搜索

```bash
# 搜索 SKILL.md 中包含关键词的文件
find "C:/Users/Matebook/.workbuddy/skills/" -name "SKILL.md" | xargs grep -l "关键词"

# 搜索中文关键词
find "C:/Users/Matebook/.workbuddy/skills/" -name "SKILL.md" | xargs grep -l "小程序\|爬虫\|搜索"
```

### Step 3：检查 archived

```bash
# 检查是否有之前整合过的 skills
ls "C:/Users/Matebook/.workbuddy/skills/.archived/" 2>/dev/null || echo "无归档目录"
```

### Step 4：联网搜索

```
# 使用 联网工具箱 搜索
# 触发词：搜索、查一下、找最好的 XXX 工具
```

搜索关键词：
- `best CLI tool for X 2025`
- `X vs Y comparison`
- `awesome-X`（GitHub 上的精选列表）

---

## 输出格式

在 SKILL.md 的"整合来源"章节，列出所有被替代的旧 skills 名称：

```markdown
## 整合来源

本 skill 整合了以下原有 skills：

| 原 skill | 功能 | 状态 |
|-----------|------|------|
| `old-skill-A` | 功能描述 | 已归档至 `.archived/` |
| `old-skill-B` | 功能描述 | 已归档至 `.archived/` |
```

| 检查项 | 说明 |

## 集成流程

### Step 1：搜索工具

```bash
# 使用 cli-anything-hub（本地）
pip install cli-anything-hub
python -m cli_hub list
python -m cli_hub search "web scraping"

# 使用 WebSearch
# 触发词：搜索、查一下、找最好的 XXX 工具
```

### Step 2：验证工具

1. 找到工具 → 读取官方文档
2. 安装工具 → 测试基本功能
3. 确认可用 → 写进 `references/工具名.md`

### Step 3：集成到 skill

在 SKILL.md 的二级"工具选择"中引用新工具：

```markdown
### 二级：网页抓取

| 用户需求 | 推荐工具 | 说明 |
|-----------|------------|------|
| 静态页面 | `requests` | 快 |
| JS 渲染 | `playwright` | 完整 DOM |
| Cloudflare 拦截 | `human-browser`（需安装） | 97% 绕过率 |
```

## 工具验证清单

| 检查项 | 说明 |
|---------|------|
| 安装成功 | `pip install` / `npm install -g` 无报错 |
| 基本功能 | 能完成核心任务 |
| 错误处理 | 失败时有明确报错信息 |
| 文档完整 | 有官方文档或 README |
| 许可协议 | 允许商用/修改（优先 MIT/Apache 2.0） |

## 示例：集成 Human Browser

```bash
# 1. 搜索
python -m cli_hub search "browser automation"

# 2. 验证
clawhub install human-browser
human-browser --version

# 3. 集成
# 在 SKILL.md 的"二级：浏览器自动化"中添加：
### 三级：Human Browser（绕过反爬）

**安装**：
```bash
clawhub install human-browser
```

**使用**：
```bash
human-browser open https://example.com
human-browser act "click the Login button"
```

# 4. 写 reference 文件
# 写入 `references/Human-Browser.md`
```

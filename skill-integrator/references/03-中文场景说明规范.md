# 中文场景说明规范

> SKILL.md 的 `description` 和正文必须用**简洁中文**，让用户一看就懂。

---

## 规则

| 规则 | 说明 | 示例 |
|------|------|------|
| 使用场景用**表格**列出 | 一看就懂 | 见下方示例 |
| 触发词用**加粗**标注 | 醒目，易识别 | `**搜索**`、`**抓取**` |
| 避免英文堆砌 | 必要时中英对照 | ❌ `Use Playwright CLI` → ✅ `使用 Playwright CLI` |
| 示例必须**具体** | 可直接执行 | ❌ `使用 image 命令` → ✅ `mmx image "一只猫"` |

---

## SKILL.md description 写法

```markdown
---
name: 工具箱名称
description: >
  统一 XXX 操作工具箱（三级层级结构）：
  一级：分析用户需求（搜索/抓取/自动化/总结）
  二级：选择最佳工具（Playwright/Agent Browser/...）
  三级：执行指令并返回结果。
  集成最佳工具：XXX、YYY、ZZZ。
version: 1.0.0
author: WorkBuddy 整合版（集成 skill-A/skill-B/skill-C）
---
```

## 快速选择指南写法

```markdown
## 快速选择指南

| 用户需求 | 推荐工具（二级选择） | 说明 |
|-----------|------------|------|
| 搜索信息、查资料 | **智能搜索** | 自动选引擎，无需指定 |
| 抓取网页内容、提取正文 | **网页抓取管道** | 自动降级，JS渲染兜底 |
| 操作网页、点击、填表、截图 | **Playwright CLI（推荐）** | 本地浏览器，支持登录态 |
```

## 触发词标注规范

在"一级：需求分析"章节中，触发词必须加粗：

```markdown
## 一级：需求分析

| 需求类型 | 触发词示例 | 跳转二级 |
|------------|------------|------------|
| 搜索 | **搜索**、**查一下**、**找资料** | [二级：智能搜索](#二级智能搜索) |
| 抓取 | **抓取**、**提取正文**、**爬取** | [二级：网页抓取](#二级网页抓取) |
```
